# 论文来源：要不要密钥、去哪拿、能得到什么

这是将来写给用户的“数据源”文档的骨架。事实只来自代码里的 `SourceInfo` 常量（`app/source_adapters.py`、`app/baidu_scholar.py`、`app/baidu_web.py`）和 `harness/sources.json` 里登记的外部事实；`tests/test_source_adapters.py` 会检查每个已注册来源在本文件里都有一节，且“要不要密钥”与 `SourceInfo.key` 一致。新增来源时先写 `SourceInfo`，再补一节；不要只改这里。

设置页“数据源”里每个来源一行（百度只有“百度搜索”一行：开关，下面一行密钥；2026-10-24 起不再提供“百度学术接口”开关，旧设置里残留的该开关被忽略）：开关、密钥输入、一个状态词、测试、清除、获取。AI 的 DeepSeek 密钥旁也有“获取”（固定指向 <https://platform.deepseek.com/api_keys>，登记为 `DS-KEY-PAGE`）。密钥只存在数据目录里该来源自己的 0600 文件，不进 `settings.json`，不出现在网址、缓存、日志和错误信息里，也只会作为请求头发给该来源自己的 https 主机。

接入状态（2026-10-23）：单元 A（适配器、密钥、设置页、测试按钮）、单元 B（每日推送、DOI 补全、语言、PDF 路线）和单元 C（创建项目候选、种子检索）已接入；第二个百度来源 `baidu_web`（百度 AI 搜索限定百度学术站点）接在同三处。学习图（beta）的刷新不使用百度来源。

## `arxiv` arXiv

- 密钥：无需密钥。
- 怎么用：没有 OpenAlex 密钥时，直接查 arXiv 自己的检索接口（`export.arxiv.org`，每 3 秒最多 1 次请求）；配了 OpenAlex 密钥时经 OpenAlex 的索引检索，OpenAlex 限流、暂停或连不上时再改查 arXiv 接口。两条路找到的同一篇论文用同一个 arXiv DOI 记录，不会重复。
- 会发送什么：英文检索词与日期范围（公开元数据查询）；不含画像、笔记、论文库和私有 ID。
- 怎么拿 PDF：arXiv 论文直接下载 arXiv 的 PDF（两次请求之间等待 arXiv 要求的间隔）。
- 外部事实：`harness/sources.json` 的 `ARXIV`、`ARXIV-PDF`。

## `openalex` 期刊与会议论文（OpenAlex）

- 密钥：必须有密钥。没有密钥时不检索期刊与会议论文：OpenAlex 的匿名额度很小、同一网络的人共用，匿名检索有时会被整体暂停，常常一篇也取不到。按 DOI 或标题补全单篇论文信息、找开放获取 PDF 这类查询不受影响，没有密钥也照常发。
- 去哪拿：<https://help.openalex.org/api-reference/authentication>（注册账号后在 API 设置里复制）。
- 环境变量：`OPENALEX_API_KEY`（优先于密钥文件）；密钥文件 `openalex.key`。
- 密钥带来什么：免费密钥把每天 1000 点（约 0.1 美元）提高到 10000 点（约 1 美元）；邮箱参数已被 OpenAlex 忽略，应用不发用户邮箱。
- 会发送什么：检索词、DOI 与标题（公开元数据查询）；不含画像、笔记、论文库和私有 ID。
- 怎么拿 PDF：OpenAlex 报告的开放获取 PDF 链接（只取 https）；没有时给出原文页面链接。
- 外部事实：`harness/sources.json` 的 `OPENALEX`、`OPENALEX-AUTH`、`OPENALEX-OA`。

## `baidu_scholar` 百度学术（百度千帆 API）

> 2026-10-24：owner 确认“百度学术接口现在是没有的，只有百度搜索接口”。设置页已删除这个开关，`user_settings.baidu_scholar()` 恒为关（常量 `BAIDU_SCHOLAR_OFFERED = False`），适配器代码和下面的说明只作历史记录保留。

- 密钥：必须有密钥（你自己的百度千帆 API Key）。默认关闭；第一次打开时有一次确认。
- 去哪拿：<https://console.bce.baidu.com/qianfan/ais/console/apiKey>（地址未核实，以百度智能云千帆平台为准）。
- 环境变量：`BAIDU_SCHOLAR_API_KEY`（优先于密钥文件）；密钥文件 `baidu_scholar.key`。实测的千帆密钥形如 `bce-v3/ALTAK-…/…`（三段，用 `/` 分隔）；应用接受字母、数字和 `. _ ~ + / = : -`。
- 百度学术接口本身的“服务暂不可用”（设置页的“测试”现在走下面的 `baidu_web`，看不到这一项；内部的 `/api/source-test` 仍可以测 `baidu_scholar`）：常见原因是百度学术检索还没有对你的账号开放（2026-10-23 实测：格式正确的有效密钥得到 404，同一密钥调用百度 AI 搜索 `web_search` 正常），需要在千帆控制台确认这项服务已开通或已获批；也可能是百度服务临时故障，或格式正确但填错的密钥（这种情况未实测）。格式不对的密钥会显示“密钥无效”。
- 密钥带来什么：中文论文的检索（题名、原文摘要、DOI、关键词、年份、期刊、百度学术页面）。没有作者、引用数、PDF 链接和具体日期，也没有按日期排序。
- 额度：百度免费每天约 50 次，超出需向百度提工单（未验证）；应用本地每天最多 40 次，**两个百度来源合计**（同一把千帆密钥，计数共用，北京时间 0 点换日，未验证），用完前不会发出新请求；24 小时内相同检索直接用本地缓存，不占额度。`tools/source_smoke.py` 的那一次请求会用掉百度的额度，但不计入本地次数。是否超额拒绝而不是计费，需要在千帆控制台确认（待办）。百度返回 HTTP 429 时，只有响应正文点明是每日额度才显示“今日额度已用完”；每秒请求数限制按“服务暂不可用”处理，稍后会自己恢复。
- 会发送什么：含中文的项目关键词（每个项目每次刷新最多 3 个）、创建项目时勾选中文后含汉字的检索式、种子检索框里含汉字的标题，以及设置页“测试”按钮的一个固定词；用你自己的密钥发给百度。不发画像、笔记、论文库和私有 ID。百度返回的 DOI 会交给 OpenAlex 查开放获取 PDF 和语言。
- 不存什么：百度的 AI 摘要（`aiAbstract`）从不请求、从不保存。
- 怎么拿 PDF：百度学术没有 PDF。有 DOI 时去 OpenAlex 找开放获取 PDF；找不到时在阅读器里给出百度学术页面、原文页面和出版方页面三个入口，由你在浏览器里登录后下载，再把 PDF 拖进阅读器附上。
- 外部事实：`harness/sources.json` 的 `CH-BAIDU-SCHOLAR`（含未核实项）。

## `baidu_web` 百度搜索（限定百度学术站点）

- 为什么有它：百度学术工具（上一节）对 owner 的账号返回 404（2026-10-23 实测），而同一把密钥调用百度 AI 搜索正常；这一节是在百度 AI 搜索里把站点限定为 `xueshu.baidu.com`，拿到百度学术页面的论文。两个来源可以同时开，也可以只开其中一个；同一次检索里两边都找到的论文（编号相同或题名相同）只留一篇，页面补在一起。两个来源给同一篇的编号是否一致未验证，所以不同日子里同一篇偶尔可能各存一次。
- 密钥：必须有密钥，和上一节是同一把你自己的百度千帆 API Key，设置里只有一个密钥框（“百度学术”块里的那一行）；两个开关“百度学术接口”和“百度搜索”只是复选框，没有自己的状态词和测试按钮；密钥行的状态词和“测试”针对百度搜索：一次请求验证密钥（计入同一个每天 40 次），结果用一个词显示（可用、密钥无效、今日额度已用完、服务暂不可用、无法连接）。
- 去哪拿：<https://console.bce.baidu.com/qianfan/ais/console/apiKey>（地址未核实，以百度智能云千帆平台为准）。
- 环境变量：`BAIDU_SCHOLAR_API_KEY`（优先于密钥文件，两个百度来源共用）；密钥文件 `baidu_scholar.key`，没有第二个密钥文件。
- 密钥带来什么：中文论文的检索（题名、摘要、关键词、百度学术页面和一个日期）。没有 DOI、期刊、作者（作者能读出来但应用不存）、引用数和 PDF 链接，所以不会去 OpenAlex 补全。日期的含义未验证（可能是页面日期而不是发表日期）。结果里的专利不是论文，会被略去。
- 额度：百度写的免费额度是每月 1500 次（约每天 50 次），之后按量计费，是否对你的账号扣费未验证，请保持计费关闭或在千帆控制台确认（待办）；“限定站点”被百度标为付费功能，目前限时免费，将来可能收费（未验证）。应用本地每天最多 40 次，**与百度学术两个百度来源合计**（同一把密钥，计数共用，北京时间 0 点换日，未验证），用完前不会发出新请求；失败的请求也计数，从不重试。24 小时内相同检索（同一个请求内容）直接用本地缓存，不占额度。缓存里每条结果保存页面、题名、日期和完整的 `content` 文本（其中含作者姓名、摘要和关键词），不保存 `markdown_content`、`snippet` 和其余字段。`tools/source_smoke.py` 的那一次请求会用掉百度的月额度，但不计入本地次数。HTTP 429 的处理同上一节。
- 会发送什么：含中文的项目关键词（每个项目每次刷新最多 3 个）、创建项目时勾选中文后含汉字的检索式、种子检索框里含汉字的标题，以及设置页“测试”按钮的一个固定词；每次只发这一句查询（最长 72 个单位，一个汉字算 2），外加固定的站点限定；你在设置里选了时间范围时再发 `week`/`month` 的时间范围；用你自己的密钥发给百度。不发画像、笔记、论文库和私有 ID。
- 不存什么：数据库里只保存题名、摘要、关键词（第一个作为主题）、日期和页面链接，不保存作者；百度返回的其余字段（包括 `markdown_content`、`snippet`）既不进数据库也不进缓存。日期：百度没说它指什么（真实样本里 7 篇的日期都在 16 天之内，很像页面日期），所以内容里有合理的“年份”时，发表年份以它为准（该年 1 月 1 日），日期同年时才保留完整日期；没有“年份”时用日期，含义未验证。
- 怎么拿 PDF：没有 PDF。在阅读器里打开 xueshu.baidu.com 页面，用你自己的百度账号登录后下载，再把 PDF 拖进阅读器附上。
- 外部事实：`harness/sources.json` 的 `CH-BAIDU-WEB-SEARCH`（含未验证项：日期含义、错误响应形状、超额是否计费、站点限定是否收费）。
