# 产品与 Brainstorming

状态：设计提案；2026-09-10。对象：单用户、低算力笔记本、首发 macOS；领域尚待用户提供。所有 A/B/C/D 都在首版计划内，不是只交付推荐 demo。

## 1. 用户画像与成功标准

用户想从“每天面对海量新论文”变成“看到少量有理由的候选，并持续留下有用的理解”。不是用更多阅读时长或点击次数证明产品有用。

约束：本地持久化，无服务器部署；便宜模型 API；默认不下载或运行大模型；预算先于开发、随功能变化复审。首发以用户现有 arm64 Mac 为开发环境，8 GB Mac 为性能验收参考。Intel / Windows 后续单独承诺。

成功：推荐中有与课题相关且不重复的论文；用户能定位解释依据；阅读中断能恢复；想法能被检索与导出；费用与资源有界；没空时不会产生惩罚和任务债务。

## 2. Brainstorm：三个产品形态

| 方案 | 优点 | 代价 | 决定 |
|---|---|---|---|
| Zotero 插件 | 复用文献管理 | 依赖宿主和插件生态，阅读/推荐交互受约束 | 用户已改为独立整理软件，不采用 |
| 独立桌面应用 | 本地文件、阅读、预算和任务可统一管理 | 需要做好批注、恢复、备份 | 采用，限制为轻量论文库 |
| 浏览器/PWA | 发布简单 | 本地持久化、文件/后台任务体验与平台差异 | 不作为首版 |

| 推荐方案 | 代价与适配 | 决定 |
|---|---|---|
| 本地 LLM / embedding | 模型下载、内存、CPU 与散热负担 | 从默认方案移除 |
| 云 embedding + 向量推荐 | 额外计费和隐私路径，跨语言较强 | 非首版必要项；增项时单独评审 |
| 稀疏关键词 + 相关性反馈 + 多样性 | 小候选池低计算量，可解释；语义召回较弱 | 首版基线 |
| 所有推荐交给 LLM agent | token 不稳定，难解释、难复现 | 不采用 |

## 3. 主流程

初始化：领域、研究问题、关键词/排除词、可选种子论文、接受预印本与否、提醒设置、模型与预算授权。中文检索词的英文扩展先人工确认，不把错误译词写入画像。

每日：增量获取元数据 → 去重 → 本地排序 → 选最多五篇 → 可选生成一批五张 AI 卡片 → 浏览/选读/稍后读/显式反馈。

默认 AI 卡片简短：一句研究问题、方法、作者报告的主要结论、推荐依据、证据限制。五篇仅在材料足够时生成；摘要不足显示未知，不能填充猜测。摘要被裁剪必须显示“仅覆盖所提供片段”。详细展开、提问另走用户触发的预算操作。

阅读：目录/论文库 + PDF + 笔记/助手。选区翻译、解释、高亮、原文定位、连续问答、保存个人想法。AI 解释和用户写的笔记保持来源区分。

归档：推荐历史不是正式收藏；收藏可记录原因。待读/阅读中/已读/暂停是独立状态，一篇可读多天。“已读”由用户标记，不能由停留时长推断。

周报：先本地聚合实际活动、笔记和问题；可选 LLM 整理有来源的摘要。没读的一周不编造学习成果。默认不上传私人笔记；用户可逐项授权使用，未授权时使用公开论文元数据和本地统计。

## 4. 反馈和节奏状态机

| 事件 | 兴趣更新 | 节奏更新 |
|---|---|---|
| 无打开/无选择 | 不更新 | 不强推原因；可合并提醒 |
| 今天没空 | 不更新 | 暂停/轻量模式 |
| 选择精读 | 有上限的弱正向信号 | 保留阅读进度 |
| 明确“对课题有用” | 强正向信号 | 不自动增加每日数量 |
| 明确“方向不相关” | 对有证据的主题弱负向更新 | 无 |
| 看不懂 | 不当作负样本 | 补背景、浅解释 |
| 已经知道 | 降低重复内容 | 无 |
| 稍后读 | 独立待办，不算已读 | 不强制次日偿还 |

允许用户关闭学习、撤销画像变更、分项目维护多个兴趣簇。长期人工偏好保留，不被一次行为覆盖。近期偏好按时间缓慢衰减。难度/阅读时间与研究方向分开。

默认：至多一次日提醒；连续三次主动“没空”后询问一次是否降频；未选论文只留历史，不积压成待办。阈值可配置且不由 LLM 自行改变。关闭/休眠期间不承诺生成新推荐；恢复后只补当前批次。

## 5. 首版范围

A：PDF 与持久化，阅读/笔记/原文定位，受限问答；先验证最难的定位与恢复。
B：一个真实数据源、候选去重、每日五篇、本地排序、AI 速览、反馈。
C：确定性画像更新、多样性、个人周报、暂停与轻量模式。
D：模型预算网关、失败恢复、备份还原、脱敏导出、安全与低配性能、macOS 安装包。

预算网关的最小版本必须先于 A 的首次真实模型请求；D 加强故障与恢复，不是把预算控制拖到最后。

暂不做：OCR、复杂公式/表格可靠结构化、全库知识图谱、云同步、多用户、Zotero/Word 引用插件、自动开放式 web agent、本地大模型、移动端。

## 6. 尚需用户决定

具体领域和关键词；代表性论文及 PDF 类型；实际最低目标 Mac；模型账户/地区/服务条款；预算基线与付费测试授权。缺少这些不阻塞文档/离线 harness，但阻塞领域推荐质量结论、真实计费结论和最终发布。
