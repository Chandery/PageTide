# 自审：创建项目功能测试修复 + Mission Control 式项目总览（2026-09-30）

自审，不是独立评审。

## 创建项目：实测方法与发现
在浏览器预览（`app-ui`，数据在 `.local/ui-redesign-data`，没有 API key）里逐项手动测试。

| 功能 | 结果 |
|---|---|
| 模式切换、取消、空字段校验 | 正常 |
| 手动创建 + 种子论文（6 种输入） | 修复后各自报告正确状态 |
| 快速创建、AI 引导的本地轮次、6 轮上限 | 修复后正常；第 6 轮后按钮禁用，服务端也会拒绝第 7 轮 |
| 刷新后恢复草稿、取消草稿 | 正常 |
| 候选论文预览 | OpenAlex 返回 503：“Anonymous search is paused while the search cluster recovers from heavy load”，属于对方服务故障，不是我们的查询问题 |
| 学习路径编辑 | 本地模式下路径为空，页面也不能新增阶段；已修复 |
| 确认创建 | 跳转到新项目，草稿缓存清除，学习路径写入 `projects.recommended_learning_path` |

修复内容：
- 早期 arXiv 种子改用落地页回查。
- 重复种子在查询前就判重，不再重复请求。
- 种子失败状态分别显示，不再合并成一条。
- 快速创建时第一轮目标不再重复记录。
- 中文目标在本地模式提取不到词时会明确提示。
- 503/429 归为 `unavailable`：预览遇到它就停止后续查询，页面只保留一个固定错误位，文案说明是 OpenAlex 暂时不可用。
- 出错时不再显示误导性的“请修改检索式”。
- 手动创建时，只要有种子失败，就停在结果页并提供“进入项目”按钮，不再 0.5 秒后自动跳走。
- 学习路径可以手动添加、删除阶段，最多 8 个，与服务端上限一致。

## 项目切换
- 第一版做成了 Cmd-Tab 式的图标条，owner 否决了，要求改成“四指上推”（Mission Control）的样式。现在的实现在 `app/static/project-switcher.js`：
  - 打开时，当前页面被克隆成一张卡片，用 FLIP 动画从全屏缩到网格位置；其余项目的卡片依次淡入，背景变暗。
  - 选中某个卡片后，它放大回全屏，其余卡片淡出。开始放大的同时加载新项目；数据到位后（最多等 0.9 秒），快照淡出，露出真实页面。
  - 在系统设置了“减少动态效果”时，不播放动画。
- 纯逻辑由 `tests/test_project_switcher.cjs` 覆盖，共 7 个测试：
  - 排序（当前项目在前，然后按最近使用）。
  - 网格布局：卡片保持窗口比例、不越界、不重叠，单个项目时不会铺满屏幕。
  - ⌥↑ 和 Esc。
  - 方向键按行列移动。
  - 捏合的累计阈值、方向反转后重新计数、停顿后算作新手势。
- 在预览中实测：
  - 点击打开。
  - 方向键 + 回车切换项目，还暂停在动画中途截图检查过。
  - 合成 ctrl+wheel 捏合：捏合打开、张开返回。
  - 点击卡片切换，⌥↑ 打开后按 Esc 返回。
  - 知识库图谱里的捏合不会打开总览，图谱缩放照常。
  - 访问过的项目显示真实页面快照，其他项目显示占位页。
  - 亮色、暗色模式都截图检查过。
- 数据与隐私：
  - localStorage 里只有 `pdh-project-mru`，是最近使用的项目 ID 列表，最多 20 个。
  - 快照只保存在当前会话的内存中，不写盘，也不上传。

## 未测 / 风险
- 选择候选论文并导入的真机流程没有跑过，因为 OpenAlex 匿名检索处于暂停状态；这一路径由 `test_guidance_session_turn_preview_and_finalize` 单元测试覆盖。
- 四指上推和 ⌃↑ 被 macOS 占用，应用收不到这两个手势。⌥↑ 和双指捏合还没在 .app（WKWebView，走 gesture 事件）里用真实输入验证过，需要 owner 实机确认。点击打开始终可用。
- 快照不记录页面内部滚动区域的滚动位置。
- 学习路径保存后，目前没有任何页面展示它。
- 本地引导只能识别英文词项。
