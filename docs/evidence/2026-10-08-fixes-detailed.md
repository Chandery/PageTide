## 已真正走完的桌面任务

学习图任务：输入中文目标/背景和未保存概念 → CmdQ/关闭窗口 → 取消后原值仍在 → 保存中文概念及简介 → CmdQ 真正退出且旧后端停止 → 冷启动完整恢复，英文/深色保持。Dock Quit 是用户亲手触发并取消，代理随后核对仍运行且草稿保留；明确记为人工辅助。

项目创建任务：手动中文名称/关键词 → CmdQ 默认 Cancel → Escape 保留输入 → 再次 CmdQ/返回审阅 → 原输入仍在并聚焦名称 → 显式放弃后退出。此草稿没有创建项目，也没有暗中确认 AI。

导入任务：选4个可见公共 PDF、忽略1个其他文件、联网关闭 → 破损 PDF 拒绝 → 真正冷启动并继续原批次 → 失败原因、离线选项、2组重复候选和3分类预览恢复 → 放弃框先 Escape/Cancel 保留 → 再显式确认放弃回到文件选择。结束论文2、反馈0、最后批次 discarded、数据库完整性正常、后端停止。导入不会自动给兴趣正反馈。

阅读任务：前台 G-DOOM 实际可见正文、图和缩略图，共8页 → 开助手、输入两行中文、Tab/Escape 仅关助手 → 同论文重开问题仍在 → 再次 Escape 关闭 PDF。该次未启用 AI；不把输入/粘贴称为真实输入法候选测试。
