# UI 重设计自审（2026-09-30）

范围：去掉紫色强调色与可选强调色，全部页面改用书签海狮 logo 的纸/墨/红配色。

- 单一色板：`app/static/theme.css` 是唯一 `:root`/深色 token 来源；index、settings、project_creation、weekly_report 均链接它。`tests/test_ui_contrast.py` 强制 index 内联样式不得重定义色板、四个页面必须链接 theme.css、强调色选择器保持移除。
- 红色（`--mark`）只用于：收藏/书签状态、当前标签下划线、字标 “Dig”、实时点、详情 kicker、图谱起点节点、当前论文行。AI 标识改为中性色，不再用彩色。
- 对比度：浅色 muted ≥ 5.18、mark-text ≥ 5.03、good ≥ 4.83；深色所有文字对 ≥ 5.08（测试脚本计算，WCAG AA 4.5）。
- 深浅模式统一使用 `pdh-mode` 存储键；无值时跟随系统；设置页“自动”会清除该键。修复了设置页与首页主题键不一致的问题。切换模式会触发 `pdh-mode` 事件，图谱实时重绘样式。
- 图谱：类别色相保留区分度，但饱和度限制在 14–32；按年份的明度映射不变（测试覆盖）。
- 顺带修复：周报“返回画像”链接误用 `class="profile-page"` 导致居中漂浮。
- 预览核对（`.local/ui-redesign-data` 数据副本，无 API key）：今日、论文库/知识图谱、画像、设置、创建项目、周报，浅色与深色；控制台无错误。
- 未改动：数据、接口、网关、提示词、预算；PDF 页面背景保持白色（阅读需要）。
- 风险：审美属主观判断，需 owner 在 .app 中确认；旧 `pdh-accent` 值在首次加载时清除。
