# 阈值冻结：把「有用」定义为 annotator >= 2（附修正后的实验 2 读法）

2026-09-11。第二张盲评表（5 篇 annotator=2 的边界样本，owner 给分 `1,2,2,2,3`）与第一张合并后的结论。

## 一致率（两张表合并，20 篇）

```
compared=20  exact=45%  within1=100%  binary(>=2)=95%
owner distribution     : {0: 6, 1: 3, 2: 6, 3: 5}
annotator distribution : {0: 0, 1: 8, 2: 5, 3: 7}
confusion (owner -> annotator):
  owner=0 -> 1 (6/6)
  owner=1 -> 1 (2/3), 2 (1/3)
  owner=2 -> 2 (3/6), 3 (3/6)
  owner=3 -> 2 (1/5), 3 (4/5)
```

## 阈值扫描

| 阈值 | 二值一致率 | 真阳 | 假阳 | 假阴 |
|---|---:|---:|---:|---:|
| **annotator >= 2** | **95%** | 11 | 1 | 0 |
| annotator >= 3 | 80% | 7 | 0 | 4 |

**决定：`useful = annotator relevance >= 2`。** 理由：一致率最高、零漏判，只有 1 个假阳（PathBridger 被判 2，owner 判 1）。`>=3` 会把 4 篇 owner 认为有用的论文漏掉。

已写入 [EVALUATION](../EVALUATION.md) 作为后续所有评估的固定口径。**注意**：阈值是在这 20 篇上事后选的，且样本很小，因此它只对**后续新候选集**有预注册效力；对已有结果要如实标注这一点。

## 修正后的实验 2 读法

在冻结口径 `>=2` 下重跑（`tools/eval_probe.py score`）：

```
system                    P@5>=2  P@10>=2
recency_baseline            1.00     0.60
keyword_date_baseline       1.00     1.00
tfidf_seed_centroid         1.00     1.00
```

- **P@5 全部饱和（1.00）**：top-5 都是有用论文，区分不了系统。
- **P@10 有区分**：`recency` 0.60，两个画像系统 1.00 → **画像排序优于纯时间基线**（k=10 时）。
- **keyword 与 TF-IDF 仍并列**，无法分出高下。

所以实验 2 的最终结论要精确表述为：**在 P@10 上，画像排序优于纯时间基线；方法之间无差异；P@5 没有分辨力。** 这既不夸大也不全盘否定。
