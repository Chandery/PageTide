# 实验 3：反馈价值对照（画像吸收显式反馈 vs 冻结画像）

2026-09-11。工具 `python3 tools/eval_probe.py feedback`。**探索性、单次切分；不是 `E-FEEDBACK-VALUE` 的通过。**

## 设置

把已标注的 45 篇按时间切成两段（严格时间顺序，无未来信息泄漏）：

```
split_date = 2026-08-29
反馈批 A = 22 篇（2026-07-29 .. 08-27）  →  14 正例 / 8 负例
评估批 B = 23 篇（2026-08-29 .. 09-08）  →  用其标签评分
```

画像变体（Rocchio 风格；IDF 只用语料=种子+批A，避免用到批B）：

| 变体 | 含义 |
|---|---|
| `frozen_seed` | 只有 10 篇种子，永不更新（冻结基线） |
| `updated_pos_only` | 种子 + 批A 正例质心 |
| `updated_pos_neg` | 种子 + 正例质心 − 负例质心（主口径 pos=1.0, neg=0.5） |

“有用”用已冻结口径 `annotator >= 2`。

## 结果（批 B）

```
system              P@5   P@10    AUC   meanRankUseful   meanRel@10
recency_baseline   1.00   0.60   0.52           11.77         1.90
frozen_seed        1.00   0.90   0.94            7.62         2.60
updated_pos_only   1.00   1.00   0.96            7.38         2.70
updated_pos_neg    1.00   1.00   0.99            7.08         2.70
```

负例权重敏感性（AUC）：

```
neg=0     → updated_pos_neg 0.96（等同 pos_only）
neg=0.25  → 0.97
neg=0.5   → 0.99   ← 主口径
neg=1.0   → 1.00
```

## 解读

- 纯时间基线 ≈ 随机（AUC 0.52）。
- 种子画像本身已经很强（AUC 0.94）。
- **吸收正反馈有小幅提升**（0.94 → 0.96）。
- **负反馈再带来提升**（0.96 → 0.99），且随负权重单调增强。
- 排序顺序 `recency < frozen < +pos < +neg` 在四个负权重下**一致且单调**。

所以核心产品主张「用反馈维护画像会更好」得到**方向性支持**，而且「显式不喜欢」的信号在正例之外还有额外价值。

## 必须说清的限制（不能当通过）

1. **样本太小**：评估批只有 23 篇，AUC 0.94→0.99 的差异在噪声范围内；单次切分，不是滚动序列。
2. **代理标签循环性**：反馈标签和评估标签**同一个 annotator**。画像可能学到的是 taomu 的偏好而非 owner 的。owner 抽检二值一致 95% 减轻但不能消除这个风险。
3. **P@5 饱和**；真正有分辨力的是 AUC / 平均排名，不是 P@5。
4. **P@10 在 k=5 上无法区分方法**，方法间差异仍不可靠。
5. 结论只覆盖当前切分、当前提示词与当前 annotator 版本。

## 下一步

1. **滚动序列**：≥10 个时间批，每批先预测锁定再释放反馈，替代单次切分。
2. **把标签验证做实**：新池 ≥40 篇盲评，降低循环性风险（`E-LLM-LABEL-VALIDITY`）。
3. 然后才可能讨论 `E-RANKING` / `E-FEEDBACK-VALUE` 是否通过。
