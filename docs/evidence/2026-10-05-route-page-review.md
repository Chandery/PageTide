# Independent review: the learning-map page and the Today panel (Route Mode slice 6b), 2026-10-05

Reviewer: one separate read-only code-review agent with a fresh context (same model family as the author, not a human). It found no XSS (every interpolation of server data goes through esc(); class names are built from escaped or client-computed constants; notices use textContent; URLs use encodeURIComponent) and 9 other defects. The author fixed all of them; the fixes were checked in a browser preview of the real server but NOT re-read by a reviewer.

Findings and disposition (all FIXED):
1. MEDIUM, a concept added after deleting the last one reused its id and inherited the old concept's "mastered" and start marks on save. Fix: a mark follows a concept only when its id AND its name are unchanged (server, route-save); duplicate names are refused by the page, validate() and add_concept().
2. MEDIUM, /api/home ran the full paper-to-concept matching on every load, even for a map that is switched off (3.0 s at 3000 papers x 40 concepts). Fix: an off map returns its size only (no matching); an enabled map's summary is cached by a signature of everything it depends on (revision, latest feedback id, paper count, exposure count, seed list, freeze) and recomputed when any of them changes; tests prove both.
3. MEDIUM, a failed mark or mode switch called load(), replacing the draft and wiping unsaved edits (the mode switch on a project with no saved map did it with a 400). Fix: errors refresh only the server revision and keep the draft; the switch is disabled until a first save.
4. MEDIUM-LOW, no guard against double clicks and no recovery from a 409 (the user saw a raw English message and every retry failed on a stale revision). Fix: a busy flag; on a conflict the revision is refreshed, the draft kept and a translated message shown; the retry works (verified in the browser).
5. MEDIUM-LOW, the literature check could overwrite edits made during its 20 s. Fix: editing is paused while it runs and its answer is dropped if the draft was replaced meanwhile.
6. MEDIUM-LOW, the check marked the draft dirty and hid every status as "unsaved". Fix: grounding annotations are tracked separately from structural edits.
7. MEDIUM-LOW, the low-interest tooltip said "few ratings" while the cause is a manual "not a priority" or mostly not-interested ratings, and promised a restore that did not exist for the automatic case. Fix: the tooltip names the two real causes and what undoes them.
8. LOW-MEDIUM, a concept name containing "/" broke prerequisite editing (the editor split a text field on "/"), here and on the creation page. Fix: prerequisites are chosen from a checkbox list keyed by id on both pages.
9. LOW, i18n gaps: the card badge title was concatenated from three pieces and the layer text sat inside a no-translate span. Fix: three whole-sentence titles; layer outside the no-translate span; the stale pack keys were removed.
10. LOW, a first save had no revision guard. Fix: the empty-route answer carries revision 0 and a first save sends it.
Tests: the reviewer noted the static tests check substrings and no test executes route-page.js. Added: node tests for the helpers (duplicate names, id-keyed prerequisites with a slash and an escaped name, the tooltip), static contracts (no await load() in error paths, revision on first save, translatable badge parts), a wider forbidden-word scan (page, helpers, Today panel, English pack: no lateness/debt/unread wording), server tests for the mark carry-over, duplicate names, the off summary and the cache; the page behaviour itself was verified by hand in the browser (conflict keeps the draft and retry works; slash names; duplicate refusal; no-map project before and after the first save).
Confirmed sound by the reviewer: escaping everywhere; the Today panel for an empty project, no map and an off map; null c.route cards; no model call from the page (the literature check sends only the first search term, on an explicit click); home_route returns 404 for an unknown project through the pre-check.
