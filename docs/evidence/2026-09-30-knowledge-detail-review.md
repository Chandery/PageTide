# 自审：知识库论文详情——类别可见性与字号（2026-09-30）

自审，不是独立评审。owner 反馈：点开一篇论文看不到它属于哪一类；右侧论文详情很多字大小不合理。

## 原因
- 类别只以 11px 灰色小标签出现在元信息下面；论文没有类别时什么都不显示。
- 大多数类别保存的是默认颜色 `#64748b`，图谱里它们都是同一个色相，无法按颜色区分；图例本来就被设计隐藏了。
- `.org-detail.has-paper .org-section-head:first-child` 同时命中了笔记区的标题行，导致“笔记”是 12px，编辑/预览按钮是 21px。
- 论文库列表的卡片按钮继承了全局 `display:flex`，标题、日期、类别横排挤在一行，日期被折成“202 / 6-08- / 26”。

## 改动
- 标题下新增“所属类别”卡片：13px 类别胶囊，圆点颜色与图谱节点一致，点击即定位到该类别；没有类别时显示虚线“未分类”胶囊；“编辑类别”放在卡片右上角。
- 默认色类别按目录顺序分配不同色相；饱和度上限从 32% 提到 38%，仍然克制。同一套颜色用于图谱节点、目录圆点、列表标签、类别编辑对话框和详情胶囊。
- 字号层级（浏览器实测计算值）：

| 元素 | 之前 | 之后 |
|---|---|---|
| 顶栏“论文详情” | 12px | 13px |
| 关闭按钮 | 34px 框 / 21px | 30px 框 / 18px |
| 标题（衬线） | 23px | 21px |
| 元信息 | 12px | 12.5px |
| 类别 | 11px 灰色 | 13px 深色胶囊 |
| 摘要 / 笔记 小标题 | 14px / 12px | 14px / 14px |
| 摘要正文 | 13px | 14px，行高 1.75 |
| 笔记 编辑/预览 按钮 | 21px | 12.5px |
| 笔记输入框 | 13px | 13.5px |

## 预览实测
- 图谱模式：点击已分类论文，显示“机器学习”胶囊；点击胶囊后目录选中“机器学习”，状态栏显示“4 篇论文 · 已定位”。
- 图谱模式：点击未分类论文，显示“未分类”；点击后定位到 3 篇未分类论文。
- 论文库模式：“编辑类别”打开归属对话框，对话框里的颜色圆点与目录、列表一致；列表卡片恢复为纵向排版。
- 亮色、暗色都截图检查过。

## 测试
- `tests/test_organization_ui.cjs` 新增两项：
  - 详情类别卡片的标记，包括“未分类”。
  - 默认色类别的色相各不相同，且与节点颜色一致。
- `tests/test_ui_layout.py` 新增一项：标题行规则不再泄漏到笔记区；列表卡片是 block 排版。

## 未测 / 风险
- 饱和度提高后是否仍符合“墨色纸面”的风格，需要 owner 目测确认。
- 属于多个类别的论文，在图谱里只取第一个类别的颜色。
- 点图谱节点时，如果目录中对应类别是折叠的，不会自动展开。
