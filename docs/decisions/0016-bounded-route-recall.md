# ADR 0016：有界路线召回与临时来源

日期：2026-10-07。状态：采用；关联 R-ROUTE-V2-04。

## 决策

Route 开启时，一次刷新最多执行三个主题。路径取当前目标前沿，使用十年基础窗口和相关性排序；探索轮转项目公共检索词、目标边缘、活动旁支和明确兴趣；新进展只取已满足且持续关注的节点。后两者使用五年近期窗口与日期排序。显式日期可替换近期窗口。目标完成不改为普通主题回退，Route 关闭保留普通关键词逻辑。

同词按完整检索策略区分：路径 relevance/paged、探索 recent/paged、关注 recent/latest。前两种满页后向下一页推进，短页或第100页后回到第一页；关注始终第一页。每次主题轮转独立于页码，查询词及概念来源在相同策略内去重。最多三主题的配额包含不同策略，不允许另外追加 distractor 请求。

每主题最多50篇。来源适配器仍采用已有的严格匹配及不足时补充搜索，正常最多六个 HTTP 请求，单个 HTTP 沿用最多两次尝试；应用层不增加重试。无过期缓存可用时，限流/来源不可用/网络失败停止剩余主题。真实请求数、限流、召回价值和资源耗时未测量。近期严格与补充结果合并后统一按发表日期排序。

## 来源与状态

`route_recall_<project>` 保存轮转游标、最多160个主题页码（覆盖40节点合法图最多129个分页主题）、最多600篇论文的来源、每篇最多3条来源。来源记录查询词、概念、原因、策略、页码、实际时间窗和本地观察时间；最多保留七天，时间倒退或上下文签名变化视为失效。项目删除同时清理该状态。来源不是论文永久分类，不改写 `project_papers.relation_kind`，同一论文可由多个主题发现。后续阶段在批次中决定具体用途。

签名由实际 Map、目标范围、关注、公共检索计划、语言策略版本和查询配置构成。不使用组织总 revision，拖动位置、编辑笔记或类别不会重置召回。实际路线变化仍失效。来源使用完整计划签名，分页另用不含探索兴趣列表的上下文签名；新正反馈带来的兴趣词变化不重置未变化路径主题的页码。关注的最新第一页不占分页缓存。相对年窗口跨日保留分页；每条来源保存当次实际起止日期。图、语言策略、显式窗口和页大小变化失效来源与分页，轮转游标保留并按新主题数折返，避免每次新反馈都从第一关键词重来。

同进程按实际数据目录和项目拦截重复刷新。跨进程在 `BEGIN IMMEDIATE` 后重新核对路线输入和最初读取的召回状态，变化则拒绝旧结果，不覆盖先提交的数据。论文事实与来源状态在同一事务保存；失败、关闭 Route 或删除项目不留下部分写入。

## 反馈、隐私与成本

探索的已确认兴趣只取有效“有用”和用户选定种子的公共标题/主题。最多读取32篇，优先最近有效反馈，生成最多6个公共短语。导入、曝光、单纯收藏、读懂及沉默不声明兴趣，撤销反馈按有效状态计算。私有种子/画像 ID、笔记、本地正文和其他项目信息不进入外部查询。

本地计划、轮转、去重、来源和事务使用0模型token，不增加AI操作或获准外发范围；既有查询配额不扩大。CLI 默认不抓实验 distractor，明确 opt-in 仅在 Route 关闭时允许。阶段05继续实现3+1+1和每日上限，阶段06–08处理生长、结构化修改和视图；本阶段不能代替这些验收。

## 证据边界

纯算法、临时库、假来源、实际适配器的假HTTP和独立子进程夹具验证策略、轮转、页码、来源上限、配置失效、布局兼容、永久归属、事务与请求边界。新打包后端通过预先填充的公开元数据缓存验证真实刷新任务和重启后的游标；出站代理阻止缓存缺失时访问真实来源。离线夹具和后端包验证不证明真实召回质量、原生窗口全流程或8GB资源目标。
