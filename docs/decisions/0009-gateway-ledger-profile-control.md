# ADR 0009：网关预留账本、AI 总开关与画像冻结/恢复语义

## 状态

已实现（2026-09-30），相关任务处于 `review`，等待 owner 输入；未做真实模型调用。

## 决策

**网关。** 每次模型调用先按登记上限写入 `reserved` 账本行，再发送；收到 usage 后改为 `reconciled`。客户端错误时改为 `released`；缺少 usage 时标为 `unknown`，并继续按预留计入。日上限只统计当天，月上限统计整月，token 和 USD 分别检查。在途预留会阻止并发调用超限。网络失败不重试，也不切换模型。AI 总开关是数据目录中的 `AI_DISABLED` 标记，关闭后包括 dry-run 在内的所有请求都被拒绝，推荐、画像和建项目仍可在本地完成。`project_guidance` 未经 owner 批准时，网关一律拒绝，服务改用本地模式。设置接口不返回、也不在 `user_settings` 保存 API Key。

**画像。** 画像冻结时记录当时最后一条反馈的编号；冻结期间画像只回放这个编号及之前、且未撤销的反馈。新反馈仍会记录，但不改变排序向量；撤销冻结前的反馈会立即生效；钉死词仍可人工修改。旧版快照没有这个编号时，沿用它存储的列表。“恢复默认”会清除冻结，把钉死词恢复为项目创建时的关键词，并在画像版本里写入原有的钉死词，方便找回。反馈事件是幂等的，同一动作重复提交不会新增一行；重复提交“有用”时，如果论文已被移出论文库，会重新保存（论文库操作本身幂等）。撤销会让画像、向量、统计、证据和周报都回到反馈之前的状态。“有用”带来的收藏是另一项用户事实，撤销反馈时保留收藏，需要到论文库单独取消。“太难”只是熟悉度信号，不作为兴趣负例。没有动作不改变任何状态。

**种子。** 只有 arXiv 编号/链接、DOI/doi.org 链接和 OpenAlex W 编号会被发送去查询；其他输入（例如自由文本标题）在本地标为 `invalid_input`，不发起请求。标识会先做 URL 编码。无效 URL 和非 JSON 响应会转成 `SourceError`，非 JSON 响应不写入缓存。单个种子出错不会中断项目创建。`/api/project-papers` 不接受客户端传入 `relation_kind=seed`。

**生命周期。** 如果有待执行的迁移且库中已有用户数据，先用 SQLite backup API 生成 `.pre-v{N}.bak`，已有同名备份时不覆盖。删除项目时，同时清理该项目的曝光、问答、已确认的引导记录，以及冻结、默认词和种子设置；论文、PDF、全文、摘要以及其他项目的反馈都保留。

## 取舍

冻结只固定学习结果，不阻止记录事件。这样用户解冻后不会丢失冻结期间的反馈。撤销不连带取消收藏，与画像重构时“反馈撤销保留收藏”的决定一致；代价是撤销“有用”后，论文库里仍保留这篇论文，UI 需要明确提示这一点。上游 arxiv-sanity-lite 把未标注样本当负例，违反“不从无动作推断不喜欢”的规则，因此不采用（见 [本地基线](../evidence/2026-09-30-reuse-baseline.md)）。
