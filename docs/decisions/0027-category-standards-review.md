# ADR 0027：论文分类标准与完整 AI 审阅

2026-10-07。用户发现周报 World Models/世界模型重复、标题片段混成方向，明确要求已有分类也审阅、AI辅助判断并删除不合理标签。取代旧词法短语立类，不改变ADR0007目录、多归属、手工编辑和撤销底座。

## 分类身份与证据

统一exact bilingual aliases与规范展示，不把词干、论文集合重合或相关概念当同义。研究方向→已定义子方向；明确方法仅放方向下，基础泛方法不自动细分。未知片段不立类，用户显式固定自定义词仍支持。已有重复类的本地预览列原名；双语平行父子按完整语义路径合并，子类依赖父合并，未选父不得提升方法为根。父级范围检查含子类论文。

## 完整审阅与边界

默认整理分类调用category_review；冻结当前范围全部已收藏论文（包括已归类）及全部共享目录，最多60类，完整目录不能裁。预检每批≤12公开标题80/摘要160片段与temporary c/p别名，不发PDF、笔记、反馈、画像、私有ID。目录/消息过大明确拒绝，篇数可以在发送前减少以满足完整wire UTF8bytes+256≤8000；output2000，一次/批、无重试、无推理或模型替代。旧审核marks不让AI漏看已分类论文。所有批次对旧类意见必须一致，新类按规范路径合并；badJSON/重复字段/缺漏覆盖/length/未知目标/循环/孤儿/不同已知概念merge/无证据新类/新方法根拒绝。

AI只是意见。完整成功且同revision/corpus/structure的方案才入本地预览；确定keep/rename/merge/delete及每纸最终归属，使用者确认整份方案后一个事务执行、一个撤销事件恢复。Delete须所有保留成员已处理，scope外或归档成员阻断；merge保留所有归属与子类。保留论文/原文/笔记，AI理由不写用户笔记。重复应用无新事件。并发变化拒绝；取消或切scope停止后续batch，已发单次不能伪称未收费。未知usage保留网关预留、不计成实测且停止；没有完整方案不保存partial。失败纯读显示原因，另点本地检查才存本地预览，不假装AI成功。

周报只读按完整canonical祖先路径并桶，论文归属去重，真实反馈事件次数保留；提示统计归并，存储类别不暗改。

## 授权、资源与证据

用户授权本轮实现和AI审阅方向；新操作范围/cap初始明确提问并保留owner_approved=false；用户随后在本会话回复“批准”，据此登记本操作true，准许已登记边界内显式调用和有界验证，不扩大总额度或其他操作，也不自动开启AI。新增操作默认关闭，原全局日/月token与USD不增；本地核心每天最低0modeltoken。单批最高10000token/$0.0048峰值缓存未命中算术，非测量。只用stdlib/已有唯一Gateway，独立审查和回归见同工作单元记录。通用术语覆盖、真实AI主观质量/tokenizer账单和8GB资源未测，旧全产品release阻断不降。
