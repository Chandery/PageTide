# ADR 0035：学习图模式（beta）放进设置，默认热点模式

2026-10-22。业主要求：把学习图整套框架收进设置里的“打开学习图模式（beta）”，只有打开后才能在主页选择学习图模式；默认使用热点模式，即根据画像推最新的论文。

## 决定

1. **一个总开关**。设置键 `routeBeta`（布尔，默认关，非布尔值被设置接口拒绝）。`user_settings.route_beta()` 只认 `true`。
2. **后端只有一个收口**。`App._route_state()` 在开关关闭时返回 `None`，`home_route()` 同样返回 `None`。每日推荐、刷新、每日维护、探索召回、批次上下文都只通过这两处读取学习图，所以关闭时全部按“没有学习图”处理，项目自己的 `mode` 与图都不改。画像与周报的 `learning_map()` 关闭时返回 `None`，报告里就没有学习图部分。
3. **数据原样保留**。关闭既不删图，也不清进度、手动标记或持续关注；`route_get()` 与学习图页的写接口没有被关掉，所以打开开关后一切恢复到关闭前。
4. **热点模式 = 现有非学习图排序加近期默认值**。仍是画像加稀疏检索，零模型调用。仅当 owner 没有设置时：时间窗默认最近 30 天（刷新与每日批次），新论文权重默认 0.5。owner 在设置里选过的时间偏好和权重优先。明确的关键词检索（`search`）保持原来的宽窗口。学习图开启且项目在学习图模式时，权重默认仍是 0，行为不变。
5. **页面在渲染前就知道开关**。服务端在每个 HTML 页的 `<head>` 注入 `window.PDH_ROUTE_BETA` 与一条样式：带 `data-route-beta` 的元素在关闭时隐藏，带 `data-route-beta-off` 的元素在打开时隐藏。没有额外请求，也没有先显示后消失的闪烁。脚本只把 `=== false` 当作关闭，所以没有注入标记的测试环境保持原行为。
6. **关闭时各处的表现**：主页学习图面板换成“热点模式”一行；项目创建页隐藏学习图和学习路径区块，句子改用不提学习图的版本，并且不要求也不保存学习图；项目页“打开学习图”、论文库图谱的学习图视图、论文详情里的学习单元与推荐用途行隐藏；直接打开学习图页只提示未开启并给设置入口。
7. **“普通排序”改名“热点模式”**。主页与学习图页的推荐方式切换、周报说明里同步改名。

## 预算与隐私

不新增模型调用、额度、外发字段或提供方。热点模式的默认只影响本地排序与公开元数据检索的时间窗（`from_date`），不发送画像、种子 ID 或论文库。核心路径每日最低模型 token 仍为 0。

## 未做与限制

- 关闭时项目创建里的 AI 引导回复仍可能带回一张学习图（同一次调用，不额外计费），页面直接忽略它、不保存。
- 项目创建页的退出确认文字仍提到“学习图”（只在对话框里出现）。
- “最近 30 天、权重 0.5”只是默认值，没有用真实使用数据验证推荐是否更好；这属于推荐质量评估，不在本单元。
- 已打开的页面不会实时感知开关变化，保存设置后返回主页（设置页保存本来就会跳回主页）或刷新才生效。
- 设置页原先显示的默认值（权重 0.2、时间偏好最近 1 周）与后端实际默认（0、不限）不一致；现在改成显示后端真正使用的默认值（0.5、最近 30 天）。以前保存过设置的用户文件里已有显式值，不受影响。
