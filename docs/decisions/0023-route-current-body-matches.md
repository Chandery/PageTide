# ADR 0023 — Current local body evidence across Route views

2026-10-07. Continues R-ROUTE-V2-08 on codex/route-discovery-rework, baseline deec31a. Updates ADR0022’s title/abstract-only learning matching rule. Categories, recommendation purpose and mastery remain separate facts.

The learning graph and Today/library context use the same local retrieval text as recommendation and progress: title plus usable abstract, otherwise title plus usable current-version local body. Body text remains bounded to the first6 pages, at most2000 characters per page and at least200 alphanumeric characters. It is never put into cards/context responses or automatically sent to a model. Graph matches still have at most2 units; learning progress still credits the strongest match only. Language policy changes and Route off do not erase this derived learning evidence.

One graph request shares the256MiB physical PDF verification allowance between saved-paper matching and additional progress evidence. Progress reuses the captured rows rather than independently recapturing the same paper. A final local identity/version/bounded-text comparison rejects the response if a captured body changed during the request, without another hash. Detail also checks its captured body. Existing128MiB per-PDF cap and restart-safe actual hash proofs remain. Cached proofs are evidence from actual prior verification, not fabricated verification.

Deferred body verification is pending rather than unmatched. Deferred fulltext-language verification does not hide a usable-abstract learning match. Progress indicates deferred evidence separately even when every saved paper is already verified. Title/body input provenance is explicit; a body retrieval source is not proof that every matching term occurs in the body, so hover says title or current body.

Every Map detail and graph exposes an explicit local re-verification action. It clears both graph/context caches and invalidates older replies. Successful fulltext saving invalidates learning caches even when the reader changed during the save; closing the reader refreshes visible learning views. Today closes its old drawer before reading, and reopening rereads current evidence. Visible cache invalidation starts a replacement read so a late save cannot abandon a newer project request. Pending caches do not automatically trigger loops. External PDF changes can be rechecked explicitly. No automatic model calls, category writes, mastery grants, source requests, whole-library uploads or new budget approval occur. Daily required model tokens remain0.

Regression fixtures and fresh packaged-backend checks establish local contracts only. Actual native clicking remains pending after the earlier browser-access policy rejection and locked Mac. No alternate surface or command workaround is permitted. E08 stays not_run, ROUTE-V2-08 stays in_progress, original release gates remain unchanged. Real recommendation value, language/model accuracy, token billing and8GB performance are unmeasured.
