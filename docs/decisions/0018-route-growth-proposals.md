# ADR 0018：明确兴趣证据、完整 Map 和用户确认的生长提议

2026-10-07，阶段06离线合同。产品定位见 重构方案。真实模型质量、tokenizer 和账单另测；新外发范围仍未批准。

生长证据只取有效 Useful 或用户主动选定的种子。路径、探索和未曝光论文相同；导入、曝光、沉默、读懂和撤销后的收藏残留不声明兴趣。已读懂单独影响掌握。新 Useful 不使无关旧提议过期；相关证据撤销或元数据变化会过期。

显式点击调用新 `route_growth_judge`，不借旧 `direction_judge` 授权。完整40节点/120边 Map 使用每次临时 c/p/d 别名，包含所有概念名称、检索词、简介、难度、类型、状态、旁支、前置和目标。最多3篇明确兴趣论文的公开标题80字和摘要180字、3条有效提议名称/简介/类型。不发送私人ID、项目、笔记、画像、反馈原文、全文、历史或其他项目。完整协议字节保守估算超过8000就拒绝，不截断Map；尚未证明分词器一致。

模型可以说已覆盖、不确定、已有节点下的新任务、必要前置缺口、新分支，也可给现有提议补证据。模型判断学习价值；本地验证引用、字段、结构、容量与循环。词语相近不替代学习价值判断；新任务可以来自已有概念附近。计数与相似度只解释证据，不禁止用户确认或手动改图。缺口预览新节点指向原节点；目标影响只计算活动前置闭包。确认才激活新节点及所有相关边，不自动替换目标。

图的语义及相关有效证据签名随提议记录。旧无版本意见显示过期，不引导探索、不自动重判；仍允许手动编辑。拒绝判断额外记录拒绝策略依赖，撤销拒绝后恢复待判断。新模型结果在事务中检查完整快照与原提议存储；确认在组织事务内再检查证据及revision，防止撤销竞争。布局不改变学习任务。失败或409刷新提议/计数，保留未保存草稿；无效回复只说未保存判断，不虚构本地判断。前置缺口的两个方向都画未确认虚线。无关兴趣不使已有提议失效。

同数据目录、同项目的内核文件锁覆盖快照、调用和保存，跨进程第二请求在调用前拒绝，崩溃自动释放。次数在SQLite事务中预留，每点击一次、每项目每本地日最多10个付费尝试，旧计数继续共用；网关未发送的拒绝或明确释放的4xx退回本次次数。5xx、超时和网络不明仍保留次数及预算预留。无重试、模型回退或后台自动刷新。`finish_reason=length` 即使JSON可解析也拒绝入库；未知usage继续按原网关留预留。

最多12条当前有效提议；页面最多5条，当前有效先显示；模型至多3条。确认查完整存储，不把显示裁剪当存在性。原始意见历史继续保留，不能在新判断时删除仍可能由组织撤销恢复的提议。已接受/拒绝后生成其他意见，再撤销，原提议仍能回来。历史容量、大库/8GB性能未测；本阶段不声称所有历史固定12条。

新 operation 上限8000/1000，参考3000/700，每次最坏9000 token/$0.0036。八次/月最坏72000/$0.0288是算术；十次/日90000超过原55000总日额度，不能保证十次都获准。原55k日/150万月/$0.15日/$1.50月不变。默认日常检索、排序、画像、归档和维护0模型token。owner_approved=false，手动编辑与离线路径可用。

离线回归和实际新包后端隔离验证另存检查记录；这些不证明原生窗口完整流程、真实输出质量或真实API费用。五字段需求、语义身份/掌握重置与固定结构修改预览仍由阶段07实施。
