# ADR 0030：审计问题逐项修复

2026-10-08。业主要求“现在把所有的问题一条一条修复”，范围是全功能报告 B01–B29 与导入报告 I01–I12，重叠仍保留映射。所有实现与验证在独立 `audit-bug-fixes` worktree，基线 8e5cfd7；原报告和主库保留。任务以 FIX-MULTIDISCIPLINE-AUDIT 为准，质量门槛不降。

## 文件和状态

论文/项目/PDF 版本在阅读与问答请求中共同绑定。清空助手开始新的持久会话，旧历史保留可追溯但不再进入新上下文。阅读弹窗让背景不可交互并限制焦点。笔记退出先等待草稿保存确认，失败保留窗口；学习图页让用户检查保存、取消或明确放弃，未确认AI不自动落图，晚输入和进行中的操作仍受保护。随机本地端口与权限边界保留。

桌面导出通过受限原生命令和保存面板，返回实际保存、取消或失败收据。全数据导出使用一致性 SQLite 快照、全部表与项目、版本和摘要；明示不内嵌 PDF/暂存附件 bytes，文件清单保留，恢复只写新目录。普通分类导出独立保留。

导入批次的审阅/查找/提交/放弃互斥，迟到上传在登记前重新检查终态。状态、数量与条目一次只读快照。resolve 的本地初始化/join/终结阶段共享短编辑锁，网络阶段每项结果核对请求起点文件 SHA 和题录；内容改变暂停供用户继续，不把旧响应写到新文件。人工选择/排除保留，新来源不会复活明确排除。不同导出身份引用同一附件时保留冲突并要求选择。归档失败整批回到审阅，失败项须补传/纠正/明确排除后才能继续；不再悄悄终结部分批次。失败数据库事务不会删除已经复制的内容寻址归档；这些校验过的副本供重试复用，不能凭失败批次身份删除可能已被他处引用的 bytes。

显式重新选择文件会读取并核对内容，而不是只凭路径、大小、mtime 跳过。上传与下载增加有界 PDF 结尾和 cross-reference/root 检查；这不是完整解释器、OCR、密码或全部页面可渲染验收。既有原件不自动改写。

## 推荐与画像

设置实际驱动数量、来源、时间和衰减；0 是合法权重。种子与新发现分开。综述/会议类型保存到规范事实；已有库加 work_type 前做一致性私有备份。未来日期候选隔离但原响应保留。科学词的明确身份与可解释匹配统一，有限术语/同义规则不能宣称通用语义理解。

库存词谱与有效兴趣证据分别展示。导入、已收藏、数字、沉默和难度不伪装成正兴趣或掌握。改显示不等于提高推荐收益；六固定目标分别复测，不用平均掩盖失败。

同一固定目标检查贯穿匹配、进度、卡片和周报；不能把学习图已拒绝的错误癌种又计成周报的单元推进。探索槽需有可核的公共来源或明确学习目的，证据不足允许少推，不用无关论文补数量。

## AI 与成本

检索、去重、排名、画像、归档和维护每日必需模型 token 仍为 0。可选 AI 的操作、输出和日/月上限及授权不增，所有请求走 Gateway；完整 wire 输入在外发前执行保守上界检查，超限保留输入并提供缩短或本地路径。计数上界不是供应商账单/tokenizer parity。

速览必须完整对应请求白名单且全部校验后事务写入。QA 回复字段有严格类型。引导、建图、修改、分类、生长改进有界回复合同与缺证据的未知表达，合法 JSON 不代替科学正确性。不存在自动重试、静默换模型、扩大外发或提高额度。真实补测使用既有开发模式和独立账本，软预算 300 万 token/$2 及原硬限额沿用；真实失败和代理分歧保留。

最终逐项状态、测试、构建和独立评审写在修复矩阵。发布、真人盲评、自然库、资源和标签有效性未测门槛不自行通过。
