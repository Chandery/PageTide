# ADR 0021 — Shared Route requirements, bounded model drafts and confirmation UI

2026-10-07. Implements the remaining local model/UI contracts of R-ROUTE-V2-07 on top of ADR0019/0020. It does not approve expanded model scope, validate real AI quality or complete phase08.

Creation and revision share five fields: goal250, known150, include150, exclude150, structure500 Unicode characters. Only goal is required. Teacher text or Markdown pasted into structure is untrusted requirement data; no file parser, tools or general import format. Known-background prose guides planning without granting mastery. Manual creation remains available with AI off/unapproved, explicit targets and at most12 initial nodes. Saved maps and revisions retain40/120/3 limits. Hint inversions warn; cycles and invalid explicit targets refuse. Public grounding preserves explicit edges.

New interactive operations route_map_create (input/output caps3200/1800) and route_map_revision (8000/4000) are separately owner_approved=false and default-off. Existing approval for legacy operations is not expanded. Creation sends only the complete brief. Revision adds the entire compact Map with request-local aliases, semantic fields, prerequisites/states, targets and a sparse human-intro protection list. Explicit defaults for active/topic/empty why reduce framing without dropping nodes/edges or prose. No papers, notes, profiles, feedback, cutoffs, private IDs, other projects or history leave through these operations.

Before an attempt, complete model/thinking-disabled/max_tokens/messages JSON UTF8 bytes plus256 framing must fit the registered input cap. This conservative check is not tokenizer parity and field maxima need not fit together. Over-budget messages refuse without truncation. Gateway encodes before reservation; invalid Unicode/serialization refuses with no ledger or provider request. Output4000/1800, one request/click, no retries/fallback/tools; length finish reason rejects even complete JSON. Strict whole JSON creation returns1–12 nodes with new identities, explicit edges and targets. Revision returns only allowlisted patches; full replacement/cropping is forbidden.

Creation allows3 paid attempts/session or project/local day, sharing existing legacy counters/claims. Revision allows2/project/local day. Invalid/length replies and unknown billing retain attempts; explicit no-send/4xx refusals refund. Counters/cache reserve and writes use short locked SQLite transactions; no network call holds SQLite. Refund reads and updates in one transaction and never recreates deleted keys. New and legacy creation share cross-process claims. Cancellation atomically ends a session and deletes its cached draft; confirmation/cancellation reject same-connection transaction reentry. Session lifecycle is checked before calls and saves. A failed legacy reservation cannot leave a permanent busy flag.

The Route page separates initial creation from existing-map revision. Revision creates a stored preview without altering the Map; restart restores the actual draft wrapper. Preview shows structure, explicit goals, familiarity resets and requirement changes. Confirm sends only the bound draft ID. Graph/effective-feedback or newer-preview changes refuse409; input and previous preview survive, and no latest-revision overwrite is attempted. Editing requirements disables old-preview confirmation. In-flight generation/confirmation disables requirement fields; newer text remains dirty if it nevertheless differs on return. Manual edits must be saved/discarded first. Creation ignores replies belonging to an earlier session. English labels and complete dynamic messages are covered.

Deterministic fixtures and freshly packaged backend checks can validate these contracts. Native-window/actual browser interaction, real model suitability, returned tokens/billing, recommendation value, fulltext-language accuracy and8GB resources require separate evidence. The browser attempt this unit was explicitly denied by browser policy and Mac native surfaces were locked; no workaround was attempted.
