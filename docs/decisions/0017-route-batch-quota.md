# ADR 0017：Route 批次用途与完成后的原子每日限制

状态：接受本地确定性实现。新增模型范围仍未批准。

## 问题

平滑探索比例、已满足前置补基础和目标完成后的普通回退不能表达学习目标路线。抓取来源不等于永久类别，同一论文可符合多个用途。并发手动和维护必须共享完成后的日限制。

## 决定

纯本地选择器分配最多五个位置：三路径、一探索、一关注。五位置增广匹配在可行时保住不同论文组成的3+1+1，先尝试未占用候选，必要时重新分配已选论文。发现缺失先互补，再路径补位；路径缺失不增加发现上限。未回答路径可重复，发现必须未展示；全部显式反馈退出候选。路径采用与进度一致的第一概念匹配。

完成后优先一个探索，次选一个关注。已有 batches.source 标记 route-completed；服务端本地日期与手动/维护共用 BEGIN IMMEDIATE 事务。并发重算后检查已生成日批次，再写批次和曝光。失败回滚不消费额度；重启、模式切换和客户端假日期不能绕过当天已有记录。重复请求返回历史批次，不新曝光、不再次自动速览。学习期间手动频率不变。

最终事务核对目标/前置/关注/手动状态、当前及冻结有效反馈（包括旧撤销）、种子、画像、检索配置、方向与拒绝状态、最后批次，以及论文标题/摘要/日期/语言/PDF身份和实际有界正文。布局不单独导致批次失效。并发变化拒绝过期结果，保留此前历史。

进度仅对存在种子、反馈或曝光的论文加载有界当前版本正文。每次生成从候选、进度、事务到卡片共享256MiB物理核验预算（收紧ADR0014的每扫描口径），每篇仍取前6页/每页2000字符；不因语言推荐规则否定已有理解。首页签名包含有关文件身份和有界正文。核验延期结果不缓存为最终进度，显示不完整并允许后续重算。未完成核验时阻止新批次，不能基于部分反馈消费完成额度；事务签名同时检查延期状态。来源解释复用已算路线；卡片语言核验也共享预算，不再无预算读文件。每篇当前PDF保存一个本地核验凭据（实际SHA与路径/device/inode/size/mtime/ctime），只在当前身份仍相同且当前SHA一致时复用。凭据不保存正文、角色或用户判断，数量不超过当前有PDF的论文数，PDF重新登记清除旧凭据；项目删除保留canonical事实及对应凭据。它允许分次核验超过内存LRU的证据，重启可复用；身份变化、移动、版本变化都须重新核验。条件写入不会提前提交调用者事务，失败/回滚保留原状态。不加载全库正文或发给模型。

## 结果与验证边界

无模型调用、无新增外发数据、无新迁移和日账表；默认每日最低模型开销0 token。来源只是线索，不能宣称AI已证明新学习价值。临时库合同与独立并发夹具验证配额、角色重叠、反馈撤销、原子回滚、跨进程/日/重启、正文归属、延期核验和中英文UI。真实推荐收益、大库/8GB资源和原生窗口体验须另验。模型扩展和原发布门槛不因此批准。
