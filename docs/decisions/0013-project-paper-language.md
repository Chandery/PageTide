# ADR 0013：项目论文语言与版本证据

日期：2026-10-07。状态：采用；推荐资格和界面合同见 [ADR 0014](0014-shared-recommendation-eligibility.md)。

## 决策

论文语言策略属于项目，与界面语言无关。理工科只允许英文；文科明确选择允许语言。旧项目和未选择的新项目保持 pending，不根据名称、关键词或现有种子自动猜学科。策略 revision 随变化递增；后续资格缓存必须包含 revision。改变策略保留已有批次与阅读历史。

首版编辑器提供 13 种语言，包括希腊文和拉丁文。配置是固定选项，避免自由文本语言名称歧义。以后可扩充选项，不把不支持的元数据语言强行改为英文。

OpenAlex 语言保存为元数据报告及来源。缺值保持未知；英文标题或摘要不填充全文语言。没有报告的新导入也不覆盖已有报告。显式新的报告可以更新已有元数据，但不修改全文核验。

全文语言核验按论文和 PDF SHA-256 保存，读状态只采用与当前 PDF 记录匹配的证据。更换 PDF 后旧核验保留，但当前状态回到 unverified；回到相同原始版本可重新使用该版本证据。初始记录方式限人工确认，本轮不自动下载或通过模型核验语言。

抽取正文记录增加来源 PDF hash；旧正文和没有来源版本的提交不伪造绑定。提取调用明确传来源 hash，过期版本保存失败，整个分页保存回滚。推荐资格阶段只采用确认属于当前文件的本地正文。语言核验不等于读懂，不更新掌握状态或兴趣画像。

## 生命周期与验收

迁移 009 不填旧项目语言、不改旧论文或原始 PDF。启动前保留一致性备份；迁移 DDL 与版本记录原子提交，失败后回滚重试。测试覆盖旧库备份读取、重复迁移、最终版本记录失败、回滚恢复、项目隔离与 PDF 替换。

所有新操作都在本地，0 模型 token。不调用模型，不改变预算或外发范围。结构与夹具验证不是语言识别准确率、真实恢复演练或推荐收益的证据。

关联：修改方案，ROUTE-V2-01 / R-ROUTE-V2-01 / E-ROUTE-V2-01。阶段评估须依实际检查证据更新；完整桌面端到端验收仍在阶段 08，不由数据基础测试代替。
