# ADR 0024：新增 Route 授权与原生重启撤销

日期：2026-10-07；状态：accepted implementation，完整验收仍在阶段08。

Owner 回复“授权啊，全都授权”，批准先前待答复的原生验收及三项已登记 Route AI 范围和上限。route_map_create 3200/1800、route_map_revision 8000/4000、route_growth_judge 8000/1000；原全局55k日/150万月/$0.15日/$1.50月保持，均需显式点击。历史旧授权保留，不用旧授权借批新范围，不把本次当无限预算或所有发布门槛通过。

实际原生重启发现：确认图修改的撤销入口只存内存，重启后丢失。新增只供页面读取的 route_page，在 GET/api/route 返回持久组织事件的 undo 身份与标签；只在快照revision与图revision一致时提供。core route_get 保持事务内调用合同，不为推荐批次读取额外快照。页面 load 恢复或清空当前 undo，迟到回复不能替换较新加载结果；撤销仍核对明确event和revision，不能撤销另一步。

人工简介、兴趣历史、服务权威掌握截止点与原子撤销合同不变。撤销修复不新增模型调用，不默认开启或自动重试。另有本轮授权的三次真实探针：创建因超长文字拒绝、修改和覆盖判断成功，见[实际证据](../evidence/2026-10-07-route-v2-08-native-acceptance.md)。返回usage只证明本次探针，不是整体质量、完整tokenizer或提供商账单校准。读取undo仍使用完整组织快照，大库成本未测。

测试覆盖重启后的当前撤销身份、撤销恢复、缺失事件清空、跨连接旧事件拒绝、revision错位隐藏和迟到load。fresh .app实际重启后按钮恢复且点击还原原名/完成状态。剩余原生语言保存与项目创建因Mac锁定未完成；原发布质量、隐私、恢复、资源和预算门槛保留。
