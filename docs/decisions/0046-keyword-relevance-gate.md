# ADR 0046：没有关联就不抓、不推荐（关键词关联规则）

2026-10-26。owner 看到“国际中文教育”项目把《新质生产力背景下企业人才发展机制研究》排在第 1 位推荐，AI 速览自己都写着“与画像钉死词无直接关联”。owner：“这样的论文就不应该被抓取啊，一定要有关联才能被抓取啊，不然都是乱推了。这个问题很严重，而且发生的情况很多很多。”

## 查到的原因（同日，只读统计 owner 的论文库副本与开发库）

- 这篇论文来自 OpenAlex，不是知网。每日抓取把项目关键词逐个交给 OpenAlex 的相关度检索（`search=`）并按日期倒序取最新的。对中文，OpenAlex 把文字拆成单个汉字匹配，所以“语法教学”能匹配任何含“语”“法”“教”“学”的论文，按日期排出来的最新几十篇几乎全无关。
- 统计（项目里抓到的论文中，标题与摘要不含任何项目关键词的比例；“展示”指进过推荐批次）：英文关键词的“世界模型”12%，展示 6 篇中 0 篇无关；中文关键词的“国际中文教育”92%（展示 43 篇中 38 篇无关），“半导体生长”100%（10/10），“高硼硅”97%（18/20），“古典文学发展史”84%（13/20）。
- 用 owner 的 OpenAlex key 实测（同一时间窗，最新 25 篇里提到该词的篇数）：原查询 国际中文教育 1/25、语法教学 0/25、二语习得 0/25、汉语语法 0/25、高硼硅玻璃 0/25；改为精确短语（`title_and_abstract.search:"…"`）后分别是 25/25、25/25、25/25、21/22、1/1。

## owner 的决定（2026-10-26，对话中逐项选择，原文选项标签）

1. 只有中文关键词的项目里的英文论文：“**Drop them (Recommended)**”——严格执行，没有关键词就没有论文；想要英文论文的项目要有英文关键词。
2. 已经抓进库里的无关论文：“**Never recommend them (Recommended)**”——留在库里（不删除，收藏和笔记不受影响），但再也不进推荐。
3. 来源本身也改：“**Yes, test with my key (Recommended)**”——用 owner 的 key 实测后改为精确短语检索（上面的数字）。
4. 学习图的“探索”位（故意推荐不属于学习图任何概念的论文）：“**Must contain a keyword (Recommended)**”——探索论文也必须提到项目关键词。

## 规则（`app/keyword_gate.py`）

一篇论文的标题、摘要（知网论文还包括它自己的关键词）提到下面任何一个词，才算与项目有关联：项目关键词（即画像固定词）；项目有学习图时，再加上各概念的检索词和名称。

- 含汉字的词按完整短语匹配（两边的空格都忽略），“语法教学”必须原样出现，同样几个字换个顺序不算。
- 英文词要求每个实义词都出现，单复数和常见词形算同一个词（model / models / modelling，analysis / analyses）。
- 不用模型、不用同义词，结果可以逐字解释。项目既没有关键词也没有学习图时不检查。

用在四处：每日关键词抓取和学习图检索抓到的论文、知网交回的论文，没有关联就不入库（学习图检索的翻页记录仍按全部结果前进）；推荐候选池里没有关联的论文标为不可推荐（原因 `no_keyword_match`），这同时覆盖规则生效前已经入库的论文。

OpenAlex 的中文检索改为：查询里每个词都是一个精确短语、全部要求出现（重复的过滤条件是“且”）；一个都找不到时去掉最后一个词再试，最多两次；不再退回模糊的相关度检索。英文检索不变。

## 影响与没验证的

- 中文项目从 OpenAlex 每天能拿到的论文会少很多（精确短语的总量：国际中文教育 190 篇，语法教学 34 篇，高硼硅玻璃 1 篇），中文论文主要靠知网。英文项目基本不受影响（现有展示里没有无关论文）。
- 英文词形匹配是简单的去后缀（含 -sis 与双写辅音），不猜不规则变化：mouse 匹配不到 mice。
- 没有在真实的每日刷新里跑过新规则；推荐质量的变化没有测量。零模型 token，不改预算。

## 独立审查后的修正（同日）

独立审查（只读、另一个 agent）发现并已修正：英文词紧挨汉字时匹配不上（“基于Transformer的”）；前缀匹配太宽（art 匹配 article、basis 匹配 based、AI 匹配 aim），改为固定的词尾表；-y 结尾的复数（study/studies）；带空格的中文关键词与 OpenAlex 查询规则不一致，改为每段都要出现；探索位只认项目关键词（不认学习图概念词），与 owner 的第 4 条一致；排序实验的干扰论文本来就该无关，不再被规则丢掉；学习图检索只为真正入库的论文记来源，返回的计数不含被丢的；已归档的概念不再算关联；一个改测试数据后变成空比较的测试补上了断言。

仍然存在、已知的：中文查询放宽后（去掉末尾词）找到的结果只停在第 1 页；新建项目时的自由检索、概念示例和学习图核验也改用精确短语，4 个以上中文词的检索放宽两次后仍要求两段同时出现，可能为空，这部分没有测量；繁简体不互通，日文和韩文的词不参与匹配。
