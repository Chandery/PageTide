# ADR 0031：用户取消总预算帽、显式测试 AI 和题目初筛

2026-10-09。业主在当前会话明确要求：“现在找不到了，但是你得先过滤一遍题目啊。现在你先修复一个新的问题，不再设置预算上限，设置里增设按钮：测试AI”。任务 `FIX-AI-SETTINGS-TITLE`；基线本地 main `f745009`。本记录取代运行时总额准入帽，保留原操作授权和单次协议边界，不授权额外付费开发测试或全产品发布。

## 总量策略与计量

`harness/budget.json` 的运行时 `aggregate_limits_enabled=false`。Gateway 不再按日/月 token 或 USD 总额拒绝请求；历史数值留存，有效上限返回 `null`，界面显示不设总预算上限，不伪造余额。取消后总花费未知且无 App 总量上界。日常搜索、去重、排序、画像、归档和数据库维护最低仍为0模型token。

每个请求仍注册操作、检查完整输入和输出上限、预留并结算，一次尝试，无静默换模型/重试。未确认用量保持预留和未知状态，跨进程原子账本与重启保留不变；设置分别展示已确认和待确认用量。`DEV_MODE`/`PDH_DEV` 仍使用独立开发账本和原日/月开发限额。原账本、AI 总开关和操作次数不重置。

## 手动连接测试

设置按钮 POST `/api/ai-test`，采用既有桌面认证、同源检查、8KB请求体上限和字段白名单。仅新操作 `ai_connection_test` 可使用临时输入的密钥并在 AI 关闭时由用户显式测试；不会保存密钥或打开 AI。省略密钥则使用已有配置。密钥仅进入固定 DeepSeek 地址的 Authorization header，不进入 prompt、账本、原始诊断或返回值；拒绝空白/非法密钥。

请求固定为 `Reply only OK.`，完整输入上限768、输出16、30秒超时、一次请求，无项目/论文/笔记/画像/历史。完整输入保守上界不是 tokenizer 实测。峰时缓存未命中注册表算术为 $0.0002496/次；实际可能更低，未作实付验证。模型和价格版本不变。2026-10-09重新读取官方[价格](https://api-docs.deepseek.com/quick_start/pricing/)与[协议](https://api-docs.deepseek.com/api/create-chat-completion/)HTML，保留 `deepseek-flash`、thinking disabled 和原峰时价，私有证据保存HTML/hash；浏览工具超时后的直接官方HTML读取成功。

UI 一次只等待一个测试，计时与结果使用当前输入版本，改密钥/重新载入设置后旧结果不能覆盖新状态。服务也有跨实例锁；并发测试返回409。无法创建测试锁或初始用量记录时，明确未发送；已发送后的核账失败保留已记预留。测试锁退出异常不会把已确认用量伪装为未发送或未知。成功显示连接结果、模型和耗时，失败说明缺密钥、认证/余额、限流、网络、服务或回复异常。未知计费显示未确认，保留预留；不回显 provider prose、响应体、秘密错误文本或由 provider 声称的模型。

## 题目初筛

目前来源语言是报告，可能和原始标题冲突。保存的原题与来源语言均保留。对当前完整标题做本地线性扫描；仅字符计数使用逐字符 NFKC 兼容化，让数学/全角英文字体仍为 Latin，原题不改写。数字、标点、emoji 和组合附加符不计票。非Latin字母至少4个且严格超过一半、来源语言报告英文时，给出标题冲突提示。此规则不能辨别正文语言，也不能保证标题语言识别完整准确。

仅英文项目在没有当前版本核验正文时排除此类候选，原因 `title_language_unverified`。已核验当前正文优先；PDF/hash变化使旧核验失效。Route、普通推荐和维护共用同一 eligibility gate，重新计算当前标题而不信客户端/缓存冲突字段。文科允许多语言时保留候选和警告；语言未知仍未知。卡片和详情分开写来源报告、正文核验和题名冲突，历史批次保留原记录但不伪称已核验。

## 验证与限制

失败先行、Unicode对照、临时 App/HTTP 与真实 settings handler 回归覆盖该合同。独立审查发现数学字体误判和重复测试HTTP异常，两项均修正并复验。检查、包与审查最终证据以工作单元为准。不修改正式库、不调用真实付费模型；模拟响应不证明真实连接、模型质量、科学筛选收益、账单或 tokenizer parity。既有全产品门槛和人工发布批准保留。
