# ADR 0015：目标范围与独立关注

日期：2026-10-07。状态：采用；关联 R-ROUTE-V2-03。

## 决策

目标范围采用当前活动目标与活动前置闭包。仅活动概念之间的活动边参与；待确认建议和归档概念不扩大范围。多目标共享前置只计一次。目标范围外旁支不阻止完成。未满足且已解锁的范围内概念构成当前前沿；无论文候选不能改变目标完成状态。

`goal_status` 为 learning、completed 或 needs_review。目标缺失/非活动、目标范围内悬空前置或循环需要检查；不猜测旧图的新目标，不把无前沿一概视为完成。手动掌握目标仍需满足其目标范围内前置。全图 `done/total` 为历史兼容保留，新页面以 `goal_done/goal_total` 展示目标。

组织数据 Route 块新增 `watch` 概念 ID 列表，旧记录读时视为空，不触发写入或迁移。关注与 `manual` 分开，明确布尔操作才更改。可以提前关注；`watched_satisfied` 只包含当前满足节点，满足撤回时关注本身保留。新开启仅允许活动概念，非活动概念可关闭遗留关注。

结构化保存按稳定 ID 且相同名称映射，重新规范化计划按相同名称映射，与当前掌握身份规则一致；删除或替换身份不继承关注。保存、切换模式、组织撤销和备份使用同一 Route 块；不新增单独事件表或模型调用。后续语义改图与反馈截止机制属于阶段 07。

## 冲突与缓存

关注经现有组织 revision 检查，非法概念/布尔值拒绝，无变化不增加版本或撤销事件。409 后干净页面同步最新图和草稿，脏草稿单独保留，避免旧名称搭配新版本号。目标进度仍由明确反馈计算，不把收藏或沉默当掌握。

首页缓存签名使用冻结范围内有效反馈、论文标题与摘要、种子、曝光、图版本和数据目录。撤销较早反馈、更新元数据或切换数据目录不能沿用错进度。不向外发送签名或原始资料。大库读取和序列化成本尚未实测。

## 验证边界

纯算法、临时库、HTTP 和前端请求回归覆盖多目标、旁支、无前沿、循环、缺前置、关注独立性、身份映射、撤销、重启和409。实际桌面包后端用隔离 HOME 验证目标与关注保存。离线合同不证明推荐收益、模型质量、原生窗口全流程或8GB资源目标。

三类召回、3+1+1、完成每日发现上限尚待阶段 04/05。日常核心新增模型 token 为 0，外发范围与批准预算不变。
