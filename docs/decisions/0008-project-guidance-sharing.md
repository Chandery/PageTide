# ADR 0008：项目引导草稿与共享论文关系

## 状态

已实现，待发布前独立审查。

## 决策

项目创建分为草稿会话、候选预览和用户确认三个阶段。AI 只能输出当前会话的结构化方向建议，不能选择论文或写入项目；所有候选由本地公开元数据检索产生。引导最多六轮，网关使用独立的 `project_guidance` 预算操作（2026-10-01 起 owner 已批准真实调用），失败时降级到本地词项解析。

论文元数据、PDF、全文和摘要属于全局规范事实；`project_papers` 记录项目关系，`project_library` 记录项目收藏。项目画像、反馈、曝光和推荐只通过当前项目关系查询。跨项目传播必须由用户在论文详情或论文库显式触发，删除项目关系不会删除仍可复用的规范事实。

## 取舍

这种模型避免重复保存同一论文及文件，也避免把一个项目的兴趣判断误传给另一个项目。旧的 `papers.project_id` 和全局 `library` 保留作为迁移与兼容索引；新代码以项目关系表为准。AI 预算和会话内容不包含其他项目数据，满足离线优先和隐私边界。

论文问答历史属于项目上下文，迁移后按 `project_id` 隔离；共享的是论文事实和 AI 摘要，不是用户问答。
