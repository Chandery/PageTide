# ADR 0036：界面留白优先；推荐池的三处规则调整

2026-10-22。业主连续反馈后定下的四条规则。

## 决定

1. **界面不放表面细节**。诊断（过滤计数、原因码、核验状态、刷新时间、覆盖日期）、机制说明、"X 不代表 Y"的安慰句、图例、字段下的提示段落都不放在页面上；后端仍计算并保存它们（例如 `recommendation_eligibility_*` 快照）。模式只是一个名字，不用示意图解释。保留的只有：标题、操作、简短状态词、真实的错误原因，以及会影响判断的几句话：AI 动作上的一句成本/隐私提示、"AI 只看到部分内容"（折叠）、"另带上了 N 项"、"用量未确认"（付费但无可用结果时不说"未使用 AI"）。界面文字从 1525 条减到 1132 条。
2. **没有 PDF 来源的论文不推荐**。没有 arXiv 编号、没有 https PDF 链接、没有开放获取页面、本机也没有 PDF 的论文，即使有摘要也不进入推荐（原因 `no_pdf_source`）；只有登录页/落地页的保留。论文仍留在项目里。
3. **热点模式的"近期"是权重，不是截止**。没有近期论文时照常推旧论文；只有业主在设置里明确选了时间窗才截止。设置页时间偏好默认显示"所有时间"。（第一版误做成默认 30 天截止，已撤回，见 ADR 0035。）
4. **来源没报语言时，摘要明显是英文就当英文**。OpenAlex 对大多数 arXiv 预印本不给语言，旧规则把它们一律当"语言未知"排除，在业主真实库的一个项目里排除了 627 篇中的 547 篇，加上误存的"最近 1 周"时间偏好，导致"没有符合条件的候选论文"。新规则只在来源没有报告时生效：本地判断（≥20 词、字母几乎全为拉丁、英文虚词比例 > 0.12），不覆盖来源报告、不写回数据库，标题文字冲突检查照常拦截中文标题。这修订了 ROUTE-V2-01"不用英文标题覆盖语言"的取向：依据是摘要而非标题，且只填空不覆盖。

## 预算与隐私

零模型调用，不新增外发字段或额度。规则 4 是本地字符串检查。

## 证据与限制

- 业主真实库的副本上实测：世界模型(main) 可推荐论文 0 → 405，具身智能 108 → 299，点"生成"得到 5 篇对题论文。
- 英文判断是启发式：极短摘要、混合语言、非英语但大量英文术语的摘要可能判错；判错方向偏保守（多数仍为"未知"）。
- 没有用真实使用数据评估推荐质量；没有独立审查。
