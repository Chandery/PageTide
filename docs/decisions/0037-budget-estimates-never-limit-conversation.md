# ADR 0037：预算只做预估，不限制 AI 对话

2026-10-22。owner 在阅读器问答里遇到“AI 不可用：完整请求超过本次输入上限”，随后明确说：“不要给 ai 对话设上限啊，预算只是用来预估的，并不是用来限制用户的”。追问回答长度时，owner 选择“对话放开，后台留保护”。同日又报告问答说“摘要节选截断、正文摘录未发送”，以及“不支持 AI 非文本输出”一类失败。这条决定由 owner 作出，不是 agent 自行批准。

## 决定

- 各操作在 `harness/budget.json` 登记的 `cap` 改为**预估**（`policy.per_call_caps = "estimate"`），用于用量显示和场景算术，不再作为准入或裁剪的依据。日/月总额帽此前已于 2026-10-09 取消（ADR 0031）。
- Gateway 只在请求放不进模型窗口时拒绝：完整请求的 UTF-8 字节上界加最少回答空间超过 `provider.context_tokens`（deepseek-flash 为 100 万 token，来源 DS-LIMITS-20261022）。字节数不小于 token 数，所以按字节准入不会超出 token 窗口；拒绝时不发送、不记账。
- 对话类操作（`conversation: true`：阅读器问答 `paper_qa`、附图问答 `paper_vision_qa`、划词翻译 `selection_translate`、建项目对话 `project_guidance`）请求模型最大输出 `max_output_tokens`（38.4 万），对话很长时缩到窗口剩余空间。其他操作（每日速览、分类建议、学习图起草等后台或结构化任务）保留 `cap.output` 作为防失控保护：DeepSeek 文档提示 JSON 模式可能一直输出空白直到上限。
  建项目对话 `project_guidance` 用 JSON 模式，同样有这个风险；owner 是在被告知这一风险后选择“对话放开”的，它属于对话，所以也放开。真出现失控时一次约 $0.46、等待数分钟，回复按截断失败处理，原有草稿不变。
- 发送前的预留改为 max(预估输入, 实际输入上界) + 实际请求的输出，未确认用量时“暂按最大值计入”仍然成立。显式开启的日/月上限（目前只有开发模式）按这份真实预留判断，不再按预估。
- 用量显示只计已确认的用量；未确认的调用按最大值占位，单独显示“另有 N 次用量未确认”，不再把占位数计入“今日消耗”。
- 窗口判断用 UTF-8 字节数作 token 上界（偏保守：英文约 3–4 字节一个 token），所以实际在约 25 万真实 token 时就会拒绝，而不是 100 万；这是“宁可少发不多发”的近似，没有分词器实测。
- 对话里的裁剪一并取消：问答发送完整摘要（原截到 800 字）、全部检索片段（原从末尾删到放进 4200）、整个阅读会话的历史（原只发最近 6 条）；划词翻译取消 1200 字限制；建项目对话发送完整目标/消息/上一问/摘要（原截到 120/140/60/80 字并压到 1200），取消 6 轮上限、40 条消息上限、目标 4000 字和消息 2000 字限制（含输入框的 maxlength），发给模型的规则也从“最多 6 轮”改为“第 6 轮起提示确认、继续帮忙”，轮次照实发送；第 6 轮起仍把草稿标为可确认，快速创建仍是一次 AI 调用。

## 不变

- 所有调用仍只经过唯一 Gateway；一次尝试、无静默换模型、无自动重试；AI 总开关、操作批准、手工触发不变。
- 默认检索、排序、画像、归档、数据库路径仍是 0 模型 token。
- 检索仍只挑最相关的片段（8 段，完整上下文 14 段，加图注），不上传整篇 PDF、其他会话、笔记或画像。
- 发送的历史就是当前阅读会话的对话，阅读器对话面板显示的也是同一份（原面板只显示最近 20 条，现在与发送内容一致）；“开始新会话”即重新开始。没有 PDF 的论文只有一个旧会话，这篇论文在这个项目里问过的都在其中，同样完整显示。这与 AGENTS.md 第 8 条“不上传全部历史/全库”不冲突：上传的是用户正在进行、看得见、可以重开的这一段对话，不是用户的全部使用历史或文献库。
- 学习图、分类建议、生长判断、简介等结构化操作的输入组成（每批篇数、片段字数）这次没有改；它们不再被 Gateway 按预估拒绝，但仍按原设计挑选输入。

## 代价与未测

- 单次花费不再有应用内上界：长会话每轮都重发全部历史，费用随会话长度增长；一次 38.4 万 token 的回答约 $0.46（峰时未命中价算术）。界面照常显示每次用量。
- 没有做真实模型调用：长历史下的回答质量、接近窗口时的延迟和真实账单都未测。
