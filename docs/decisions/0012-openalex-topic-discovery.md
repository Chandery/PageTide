# ADR 0012：OpenAlex 主题检索（创建项目与逐项目刷新）

## 状态

已实现（2026-10-04），待审查记录收尾。真实 OpenAlex 请求在 owner 终端里实测（见 `docs/evidence/2026-10-04-openalex-discovery-checks.txt`）。多学科渠道的完整方案在 `worktree-channels` 分支（ADR 0010），本 ADR 只修本分支 OpenAlex 适配器里的问题，改动刻意保持小，便于之后合并。

## 背景

owner 新建“半导体生长”项目，创建页没有任何候选论文。原因不是没接 OpenAlex，而是创建页的检索方式把结果全部筛掉了。实测（2026-10-04，同一把 API key）：

| 请求 | 命中 |
|---|---|
| arXiv 来源、标题检索、中文词“半导体生长” | 0 |
| arXiv 来源、标题检索、`semiconductor growth` | 5 |
| arXiv 来源、标题检索、`semiconductor crystal growth` | 0（标题必须包含全部词） |
| 任意来源、标题检索 | 35 |
| arXiv 来源、标题+摘要检索 | 38 |
| 任意来源、标题+摘要检索、文章 | 1165 |
| 中文词的相关度检索 | 54251（多为中文期刊论文） |

同一原因也让项目“古典文学发展史”至今没有论文。

## 决策

1. **新的主题检索 `OpenAlex.discover_topic`**，供创建页（`guidance_search`）和逐项目刷新使用：英文短语在**标题和摘要**里匹配（每个词都要出现）、不限来源（期刊与 arXiv 都包含）、类型限定为 article 或 preprint；创建页按 OpenAlex 相关度排序（用户在挑选），日常刷新按时间倒序。严格匹配少于 3 篇时，用相关度检索补足；含中文的短语直接走相关度检索（标题检索在英文标题的索引上必然为空）。每篇论文带 `match_mode`（strict 或 relevance）。创建页不设日期下限；刷新对所有关键词（含中文）都沿用 `from_date`，并按时间倒序——日常信息流应该是新论文，中文关键词因此可能暂时没有结果（OpenAlex 的中文文献多为较早年份），这是如实的结果，不是错误。
2. **检索短语先清洗**：去掉 `,` `|` `:` 引号和反斜杠，短语不能改变 OpenAlex 过滤器的结构；清洗后为空则不发请求。
3. **AI 引导的提示词加一句**：`search_queries` 给出英文检索式，用户用中文描述时再加中文检索式；`keywords` 用用户的语言。登记的提示词文件与代码里的系统指令同步；`harness/budget.json` 的 `project_guidance` 上限不变，估计多 40–60 token（估算，未实测），仍在 instructions 分项（上限 350）内。
4. **逐项目刷新**：项目有关键词时，对其中最多三个各发一次请求（`order="recent"`），不再对所有项目写死 “world model”；默认项目或显式给了 `search` 时保留 DATA-01 的 arXiv “world model” 配方。
5. **种子选择器 `search_works`**：标题检索（取得比展示的多）加相关度检索，按标识和保留非 ASCII 字符的标题键去重（独立审查发现原先的 ASCII 规范化会把纯中文标题全部丢掉），再按“标题与输入的吻合程度”本地排序，输入 `LeWorldModel` 时论文本身排在 “Fast LeWorldModel” 之前。
6. **缓存新鲜度**：`_fetch(url, ttl)`。论文记录 7 天、搜索结果 24 小时后重新请求；联网失败、被限流或返回非 JSON（例如认证门户页）时仍使用过期的副本；文件日期在未来（系统时钟被调回）视为过期。`ttl=None` 保持原来的永久缓存。
7. **额度可见**：每次响应把 `X-RateLimit-*` 记到缓存目录的 `ratelimit.json`，设置页显示“OpenAlex 额度剩余 N / M”。有 API key 时请求后的停顿从 2 秒降到 0.3 秒（额度是匿名的 10 倍）。

## 隐私与预算

- **新增的外发行为（需要 owner 知晓并确认）：** 逐项目刷新现在会把该项目的关键词（最多三个；其中包括用户在画像里“钉住”的词，`pin_terms` 会把它们写成项目关键词）作为公开元数据检索词发给 OpenAlex，每次刷新都会发。之前日常刷新只发常量 “world model”。发送的不是论文 ID、笔记或画像权重；创建页的检索式本来就会发送并在页面上说明。`owner_approved` 保持 false，等待 owner 确认。
- 引导提示词多了一句，在已登记的 instructions 分项内，没有提高任何上限；英文界面下该句与“用英文书写”并存，检索式属于数据而不是说明文字。
- 发往 OpenAlex 的仍是用户在创建页确认的关键词/检索式和公开元数据查询；没有新增外发内容，没有新增模型操作，没有提高任何上限。
- 每个检索式最多 1–2 次请求（严格 + 补足），刷新每个项目最多 3 个关键词。额度由设置页显示。

## 已知限制

- 中文文献：OpenAlex 对中文的覆盖以较早年份的期刊论文为主，质量参差（例如教学类短文）。要覆盖知网、万方等，需要 ADR 0010 的渠道方案。
- 相关度排序可能把很老的经典论文排在前面（创建页是挑种子，这是有意的）。
- 引用与相关论文数据在 OpenAlex 上对预印本仍然缺失（候选池 200/200 缺失），图谱类功能需要别的数据源。
- 合并 `worktree-channels` 时，本 ADR 与其 `app/channels/openalex.py`、`app/sources.py` 的改动会冲突，需要人工选择；`title_and_abstract.search` 的做法两边一致。
