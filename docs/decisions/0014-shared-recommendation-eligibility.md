# ADR 0014：共享推荐资格和当前正文

日期：2026-10-07。状态：采用；完整 Route 重构仍待后续阶段。

## 决策

普通推荐、Route 推荐和后台维护共用本地资格入口。项目须显式选择语言策略；理工科英文，文科按允许语言。元数据通过只代表初筛，未核验的全文必须标注。已核验语言只采用对应当前 PDF 且物理版本匹配的证据。

可用摘要或当前 PDF 版本的有效本地正文才可推荐。空白、已知摘要占位文字、只有 PDF 链接、只有原文页及没有抽取正文的文件都不能替代内容。原始论文与历史批次保留。正文最低条件为 200 个字母或数字字符；该阈值是保守规则，不是质量实验结果。

本地排序、反馈向量和路径匹配统一选择可用摘要，否则使用有界正文。每篇最多取前 6 页，每页前 2000 字符。资格与推荐所用的正文片段只在本地计算，不扩大现有主动阅读问答的外发合同。本轮不自动下载或核验全文语言。

## 来源与资源

阅读器对实际加载的 PDF 字节计算 SHA-256，缓存查询和提交都带来源 hash。切换论文或文档后忽略迟到响应。服务端正文读取核对当前版本及物理文件；旧提取无 hash 时保持未绑定，不自行改成当前版本证据。用户主动打开旧归档文件时可建立缺失的 hash；若已有 hash 与文件不符则要求重新导入，不重标旧正文。

单文件核验最多 128 MiB，每次资格扫描新读取最多 256 MiB。读取只覆盖最初预留的文件大小；文件增长、缩短或身份改变时拒绝核验结果。摘要值缓存按路径、设备、inode、大小、mtime 和 ctime 保存，最多 1024 项。另保留有界扫描游标，下一轮从首个暂缓项开始，避免 LRU 淘汰造成尾部永久跳过。进程重启安全地重新核验；这些规则不是 8GB 机器的性能实测。

最终写批次只比较本轮核验前后保存的文件身份，不额外全读 PDF。采用的 PDF hash、路径、元数据语言、摘要与全文语言记录必须与选取时一致。策略、项目或来源变化时拒绝本轮，不自动重试，也不写曝光。资格报告通过项目存在和策略 revision 的原子条件保存；删除项目后不能重建孤立缓存。批次与曝光写入在最终数据库事务检查后提交。

## 验收与边界

离线夹具覆盖语言冲突、PDF 替换和文件修改、旧正文、占位摘要、纯标点、策略修改及项目删除竞态、核验饥饿与增长文件预算。HTTP 验证设置与来源合同；前端验证设置保留、重复提交和迟到文本。模型调用新增 0，外发范围不变。

人工核验准确率、推荐收益、真实资料库性能和原生窗口全流程仍需另外验证。阶段 03 至 08 的目标范围、发现配额、生长和结构化修改不由本决策完成。
