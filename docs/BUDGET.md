# 预算边界与每日最低开销（提案，未批准）

2026-09-11。本页解释可复算预算表，**不授权任何真实调用**。机器可读事实源是 `harness/budget.json`，表格由 `python3 scripts/budget.py --write` 生成，见[生成状态](BUDGET.generated.md)。价格与 token 参考详见 `harness/sources.json`。

## 1. 每日最低模型开销：核心是 0 token

推荐与画像主链**不调用生成模型**，每天最低模型 token 为 **0**：

- 论文元数据搜索、候选缓存、去重、版本规范化
- 稀疏排序（BM25/TF-IDF + 线性分类器）、MMR 多样性、曝光控制
- 显式反馈、确定性画像更新、可撤销/可重放
- 归档、SQLite/FTS5 维护、本地周报统计、本地导出
- 手工笔记/高亮、PDF 文本抽取

这些操作**不是零成本**，只是零模型 token。真实成本是：元数据 API 请求数与限额、CPU 时间、峰值内存、磁盘/索引体积、网络外发数据。这些必须在实验中按候选数量实测，当前均为 `not_run`。

## 2. AI 可选层的每日/每月开销（提案）

只有你要求「速览、追问、周报润色、划词翻译」时才产生 token。登记的操作与 envelope：

| 操作 | 触发 | 参考输入 | 参考输出 | 上限输入 | 上限输出 |
|---|---|---:|---:|---:|---:|
| `daily_triage` 五篇速览 | 后台，≤1/天 | 3,000 | 900 | 4,200 | 1,300 |
| `llm_rerank` 混合重排（已批准额度，默认关） | 后台，≤1/天 | 8,000 | 600 | 12,000 | 1,000 |
| `weekly_digest` 周报润色 | 后台，≤1/周 | 2,800 | 700 | 4,200 | 1,100 |
| `paper_qa` 有界追问 | 交互 | 2,600 | 650 | 4,200 | 1,100 |
| `selection_translate` 划词 | 交互 | 700 | 200 | 1,200 | 500 |
| `query_expand` 关键词扩展 | 交互，一次性 | 600 | 200 | 1,000 | 400 |

**最低 AI 开启成本**（`daily_triage` 1/天 + `weekly_digest` 1/周，DeepSeek peak cache-miss 计价）：

- 每日参考约 **4,500 token**（约 **$0.0023/天**）；上限约 **10,800 token/天**（约 $0.0054）。
- 每月（30 天 + 5 次周任务）参考约 **134,500 token ≈ $0.068**；上限约 **191,500 token ≈ $0.098**。
- DeepSeek 低峰价为峰值一半，实际可能更低；本表按峰值计价，**不假设缓存命中**。

**更重度使用**（速览 + 每天 5 次追问 + 2 次划词）：参考约 **25,450 token/天**、月度参考约 676,000 token ≈ $0.33；请求上限的月度需求约 1,088,500 token，**超过提案的 800,000/月**，会被拒绝，需另行批准更高额度。

**混合大模型重排（ADR 0003）**：`llm_rerank` 每日一次、≤20 篇摘要，默认关闭。owner 已批准覆盖它的更高额度：加上速览与每日 5 次追问后，请求上限峰值日约 **50,300 token**、月度需求约 **1,376,500 token**，均在已批准额度内。它仍默认关闭，直到 `EVAL-01` 对照稀疏基线证明有增益且你启用。

**重试压力场景**（速览2+追问10+划词4+周报2 同日）上限约 81,400 token/天，超过 45,000 日限额，会被拒绝。这只表示需求量，不代表获准执行。

所有数字都是**未实测的计划 envelope**：参考量来自 arXiv 摘要长度的少量测量与 DeepSeek 官方 token 比例（英文约 0.3 token/字符），不是你的领域实测；未经离线 tokenizer 校准前不得称为账单或保证。

## 3. 授权顺序

1. 确认研究方向、种子与实验方案。
2. 核查元数据来源许可、查询词外发、速率与账户额度；私人种子 ID 也揭示兴趣。
3. Owner 已于 2026-09-11 接受上限，并随后批准覆盖 `llm_rerank` 的更高额度（后台 26k/交互 35k/合计 55k 每日、150 万每月、$0.15/日、$1.50/月）。`llm_rerank` 仍默认关闭，启用前需对照证明增益。
4. 若确认，实现唯一预算网关：并发/日/月预留、逐次尝试记账、未知 usage 重启保留、无旁路、无静默换模型。旧 Key、旧校准、旧批准都不能替代授权。
5. 真实调用前用离线 tokenizer 校准计数，并核对当前 provider 价格页。
