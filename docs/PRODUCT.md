# 产品定义：推荐与画像优先

2026-09-11 重规划。旧 ABCD 路线退出执行，历史见 [归档说明](archive/README.md)。本轮交付是调研、决策依据和新验收计划，不是新产品已经实现，也不授权付费调用。

## 1. 主体是什么

PaperDigHelper 的主体是：**根据你的研究问题推荐值得看的论文，并根据你明确给出的反馈维护可解释、可修改、可撤销的用户画像。**

最短闭环：

```text
研究问题 + 少量种子论文
  → 候选论文与来源覆盖
  → 推荐列表、推荐依据、未知之处
  → 有用 / 不相关 / 以后再看 / 没空 / 看不懂
  → 可查看的画像变化与撤销
  → 下一批推荐，对比是否真的改善
```

没有 PDF 浏览器也应能验证这条闭环。阅读通过论文网页或已有软件完成；不需要先搬迁论文库、导入全文、写插件、实现笔记系统或完成 API 校准才能开始推荐实验。

## 2. 什么才算成功

- 推荐比“关键词 + 日期”基线更有用，而不是推荐列表看起来更丰富。
- 覆盖你真正研究的领域；找不到、摘要缺失、来源延迟要可见。每天不必凑足五篇。
- 每条推荐能说明来自哪些兴趣、种子或反馈；词法命中解释不是“论文已证明”的总结，外部黑盒分数也不能伪造解释。
- 画像是你能检查和纠正的数据，不是模型不可见地写出的一段“用户性格”。
- 不操作、没时间、以后再看、看不懂都不等于不喜欢。收藏也不自动等于强正样本。
- 关闭电脑或暂停几天，不补发积压“阅读债务”。已有推荐与反馈离线可查看、导出和恢复。
- 推荐和维护画像的质量要分别评估；相关性分数、测试覆盖率、点击量不能替代你的判断。

数值门槛与实验协议见 [ROADMAP](ROADMAP.md) 和 `harness/evaluations.json`，均为待确认目标，不是已通过的指标。

## 3. 最小用户画像

初始只保存可解释结构，算法权重由对照实验决定，不预先绑定 Rocchio、SVM、embedding 或某一框架：

| 内容 | 来自哪里 | 怎样更新 |
|---|---|---|
| 项目 / 研究问题、人工关注和排除主题 | 你明确填写 | 你编辑，版本化保存 |
| 正向种子和明确反例 | 你确认的论文及原因 | 显式添加 / 撤销；未标注候选独立保存 |
| 长期偏好 | 人工固定项、被确认的稳定反馈 | 不因短期没使用而衰减 |
| 当前探索方向 | 近期明确反馈 | 有上限、可冻结；衰减策略先做实验 |
| 熟悉程度 / 时间状态 | “已了解”“看不懂”“没空” | 与兴趣分开，不作为不相关标签 |
| 反馈事件和画像版本 | 每次操作的原始记录 | 记录项目、论文版本、原因、时间、撤销关系；可重放 |

先支持一个研究项目，但存储必须带 project_id，测试跨项目隔离。不在首轮建设泛用知识图谱或跨用户协同过滤；单个用户没有足够行为数据支撑这些额外复杂度。

## 4. 复用优先级

1. **现成系统直接能用，先试用，不另写一个。**
2. 现成系统只缺少反馈语义或本地状态，优先小范围适配 / 上游贡献。
3. 只有端到端系统不适配时，才组合现成抓取、稀疏检索、推荐和导出库。
4. 只有协议/领域需求确有缺口，才自建薄适配层，并留下“不直接复用”的证据。

选型要比较实际代码、许可、隐私和运行开销，不能只看 README 或星数。既有 Electron、TypeScript、SQLite schema、tokenizer、PDF 代码都不是新架构必须保留的前提。

## 5. 范围与暂不做

**核心首轮**：领域与种子、数据源验证、基线推荐、显式反馈、画像检查与撤销、重复控制、最低限度结果展示与原文链接、恢复及本地导出。

**已承诺但后置的第二层**（你明确需要，独立验收，不阻断推荐核心）：本地论文整理与阅读捕获——收藏理由、启发/思考、笔记、高亮锚点、原文跳转、划词翻译/解释，以及可选 AI 速览/追问/周报。顺序由 `READ-01/02`、`AI-01..03` 的 gate 决定，不需要先完成它们才能验证推荐。

**可选接口（不做也不影响核心）**：Zotero/JabRef 只读导入或链接、内嵌 PDF 预览。确需内嵌时优先复用成熟组件并单独验收许可、选区/锚点与恢复。

**仍不默认引入**：托管后端、云同步、遥测、本地大模型/embedding权重下载、付费模型、私人全文/笔记外发、无界自动 agent 循环。旧资源/隐私约束作为安全下限保留；若某个候选必须改变它们，先提交取舍给你，不暗中启用。

## 6. 现在需要你的输入

- 一个当前研究问题，以及大致领域和语言；允许先有一个粗略方向。
- 5–10 篇你认为有用的论文，最好再给 3–5 篇“看起来相关但其实不想看”的论文及原因。没有种子也可以先人工筛选少量公开候选，不用先安装论文软件。
- 当前如何收集/阅读论文：网页、文件夹、Zotero、JabRef 或其他；这只影响可选导入路径，不阻断核心定义。
- 是否首版就包含阅读/笔记/划词层（决定 `reading` 阶段是否提前）。
- 是否默认开启 AI 速览；是否接受 [BUDGET](BUDGET.md) 提案的每日/每月 token 与金额上限。

缺少这些仍能完成通用调研和协议设计，但不能假造你的领域、训练标签或推荐质量结论。选定源后再询问具体账户/外发授权，不先要求你交出全部数据或 API Key。
