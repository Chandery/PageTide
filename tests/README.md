# 当前测试的边界

`test_budget.py` 和 `test_harness.py` 是Python3.9+标准库的离线契约测试，不运行应用、不联网、不访问私人库。

- 当前预算必须没有供应商/模型操作，模型限额与重试为0；不得继承旧tokenizer或网关完成标记。
- 未来模型算术用独立合成fixture检查日/月与周任务峰值、重试需求、预留、缓存费用、usage一致性和生成表漂移。fixture不是供应商选型、真实费用或授权。
- 仓库检查覆盖声明阶段、任务循环/证据/需求链接、风险分类、prompt登记、来源过期、批准类型及发布阻断。

旧PDF/IPC/SQLite/模型网关应用测试、GUI fixture和生成应用源码的脚本已随旧实现删除，不以删除失败测试宣称旧产品修好。当前没有应用源码或Node入口；运行本目录测试不会生成旧应用。

新推荐/画像实验仍未运行。未来按新任务增加领域数据、反馈撤销/重放、出站边界、实际资源与恢复验证，不按旧A-D路线补建配套。每个真实评估须记录版本、样本来源/许可/哈希、环境、命令、阈值、结果和审查者；未运行项保持 `not_run`。
