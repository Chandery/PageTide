导入已有论文库

把你已经整理好的 PDF 带进来：几篇、整个文件夹，或 Zotero 导出的文件夹。原文件不会被改动，应用会复制一份归档；导入的论文只进论文库，不会被当作你的兴趣信号。

  1. 选择
  2. 读取与匹配
  3. 确认
  4. 完成
或把 PDF、文件夹拖到这里 子文件夹会按层级整理成分类；以点开头的隐藏文件和系统文件会被忽略。
从 Zotero 导入
  1. 在 Zotero 里右键要导入的分类（collection），选「导出分类…」。
  2. 格式选 BibTeX 或 RIS，勾选「导出文件」，保存到一个文件夹。
  3. 回到这里，点「选择文件夹…」选这个导出文件夹。元数据直接读导出文件，不需要打开 Zotero，也不会碰 Zotero 的数据库。

导出文件夹本身会作为一个分类；每个 collection 请分别导出一次。

    导入选项

    会把从 PDF 里识别出的 DOI、arXiv 编号和论文题目发送给 OpenAlex，用来查找标题、作者、摘要等公开元数据；PDF 文件本身和你的论文库不会上传。关闭后，导入本身不会联网，没有导出文件的论文都按 PDF 原样入库；之后你在确认页里主动「查找」时，输入的文字才会发给 OpenAlex。

    替换时旧的 PDF 会留在这篇论文的文件历史里，不会删除。

    Zotero 里有些条目只有题录、没有附件。勾选后它们也会进论文库，但没有 PDF 可读。
