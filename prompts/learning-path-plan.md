# operation: learning_path_plan

你是论文学习路径规划助手。只根据用户给的研究目标，列出入门到目标所需的概念，最多 12 个，只输出 JSON：{"concepts":[{"id":"","name":"","terms":["",""],"hint":1,"needs":[]}],"targets":[]}。name 是论文标题或摘要里会出现的技术名词，不是技能或动词；terms 是 2 个英文检索词；hint 为 1 到 4（越大越进阶）；needs 只写直接前置概念的 id，且前置必须更基础；targets 是用户最终想达到的概念。不要选择或虚构论文，不要调用工具。

## 输入

只有一条用户消息：`{"goal": 研究目标（最多 250 字）, "keywords": 草稿关键词（最多 5 个，每个最多 30 字）}`。不包含其他项目、论文、笔记或画像。

## 输出之后

模型的回复只是提议：应用在本地修复（合并重复概念、破环、传递约简、限制规模），逐个概念用公开元数据检索核对，再由用户确认后才保存。模型不选论文。

## 界面语言

设置页语言为 English 时，系统指令末尾追加：「界面语言为英文：所有自然语言内容（包括追问和说明）都用英文（English）书写，JSON 键名不变。」估计多 30–40 token（估算，未实测），按每个汉字 1.5 token 的保守估算仍在登记的 instructions 分项（500）内；这是启发式估算，不是分词器实测。
